- 다른 게임의 스크린샷은 레퍼런스로만 씁니다. 저장소와 게임에는 넣지 않습니다.

### 01-idle-8dir/ (2026-10-11)
- 사용한 프롬프트: 테스트 0, 완성 캐릭터 1장. 원문은 `metadata.json`의 `prompt`에 있습니다.
- 설정: 캔버스 64×64, 템플릿 mannequin, low top-down 시점, 8방향.
- 결과: 캐릭터 키 57~58px. 8방향 모두 같은 인물로 유지됩니다.
- 어긋난 점:
  - 무기가 카타르가 아니라 휜 칼입니다.
  - 머리색이 백금보다 모래색 쪽입니다.
  - 크기가 96px 규격이 아닙니다. 캔버스 128×128로 다시 돌려야 합니다.
- 파일:
  - `Idle/rotations/*.png`: 원본
  - `montage_8dir_4x.png`: 동·남동·남·남서·서·북서·북·북동 순서, 4배
  - `original.zip`: 받은 그대로
