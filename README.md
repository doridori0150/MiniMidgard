# 미니 미드가르 (Mini Midgard) — v0.2

고전 2D MMORPG(라그나로크 온라인) 감성의 **싱글 방치형 RPG**. 이름·그래픽·음악은 모두 오리지널이거나 자유 라이선스 에셋입니다.

**플레이:** https://doridori0150.github.io/MiniMidgard/ (main에 push하면 GitHub Actions가 자동으로 빌드·배포)

## 실행

```bash
npm install
npm run dev        # http://localhost:4200 (같은 Wi-Fi의 폰에서도 Mac IP:4200)
npm run build      # dist/ 정적 빌드
npm run sim -- 120 swordsman,acolyte,mage 3   # 헤드리스 밸런스 시뮬 (분, 파티, 시드)
```

## 구조

```
src/game/      규칙·데이터·시뮬레이션 (DOM 없음 → tools/sim.ts가 그대로 사용)
  data/        elements, classes, skills, items, monsters, zones
  stats.ts     파생 능력치(ATK/MATK/HIT/FLEE/ASPD…)
  world.ts     실시간 전투 시뮬(타깃팅·스킬 AI·보스 패턴·드롭·경험치·전멸)
  state.ts     세이브·인벤·장착·정련·카드·상점
  offline.ts   오프라인 보상
src/render/    캔버스 렌더러 (코드로 그린 SD 캐릭터·몬스터·아이콘·배경·이펙트·대미지 폰트)
src/ui/        Preact UI (HUD·패널·모달)
src/audio/     WebAudio SFX + BGM
public/audio/  무료 효과음/음악 (출처: docs/CREDITS.md)
```

## 라이선스 메모

- 효과음·BGM은 CC0, **마을 BGM "Waltz"(Peter Eastman)만 CC-BY 3.0 → 크레딧 표기 필수**(설정 → 크레딧에 표시 중).
- 글꼴: 갈무리(Galmuri), SIL OFL 1.1.
- 원작의 스프라이트·이름·음악은 사용하지 않았습니다.

## QA 팁 (개발 모드)

브라우저 콘솔에서 `__step(ms, frames)`로 시뮬을 강제로 진행·렌더링할 수 있습니다(숨겨진 탭에서도 확인 가능). `__game`으로 상태 접근.
