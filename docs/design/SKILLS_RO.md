# 스킬 원작 맞추기 + 추가 (설계서)

> 작성 2026-10-08.
> 사용자: "스킬이 원작이랑 다른데 원작이랑 맞춘 다음 + 스킬 추가 가능해?"
> - **1단계**: 원작 클래식(프리 리뉴얼) 1차·2차 직업의 스킬 목록, 퀘스트 스킬, 최대 레벨, 선행 조건, 메커니즘을 맞춘다.
> - **2단계**: 빌드(BUILD_TREE.md)에 필요한 스킬을 더한다. 일부는 원작에 이미 있다(턴 언데드 = 정화, 좌우손 수련 = 이도류, 페코 탑승).
>
> **이름**: 저장소가 공개라서 원작 고유 명칭(매그너스 엑소시즘, 로드 오브 버밀리언 등)은 쓰지 않는다. 뜻이 통하는 오리지널 한국어 이름을 쓴다(지금처럼 강타, 대퇴마, 천둥왕의 심판).
> - 메커니즘·레벨·선행 조건은 원작과 같게 한다.
> - 일반어 이름(힐, 축복, 하이딩)은 그대로 써도 된다.

---

## 0. 원칙

1. **전투 스킬은 원작 공식대로**(배율·타수·시전·딜레이·SP·범위·상태이상). 수치는 RateMyServer pre-re, iRO Wiki Classic, rAthena pre-re `skill_db`를 기준으로 하고 방치형 속도에 맞게 비례 조정한다.
2. **방치형에 맞게 바꾸는 유틸 스킬** (규칙을 바꾸되 정체성은 지킨다)

   | 스킬 | 바꾼 규칙 |
   |---|---|
   | 텔레포트 | 주변에 몹이 없으면 맵 안의 다른 몹 근처로 순간이동 → 사냥 효율 + |
   | 워프 포털 | 마을↔사냥터 이동 시간 0, 파티 귀환 |
   | 노점 | 잡템·장비 판매가 + (상인 판매 패시브) |
   | 감정 | 미감정 장비가 생긴다. 희귀 이상은 감정 전까지 옵션이 숨겨지고, 감정 스킬이나 돋보기로 감정 |
   | 무게 증가 | 가방에 무게 개념이 없으므로 물약 자동 사용 효율 / 카트 회전 피해 보너스 |
   | 사이트 · 루아흐 · 센스 · 디텍팅 | 숨는 몹(하이딩·클로킹 몹)을 드러낸다. 센스는 몬스터 상세에 약점과 내성을 보여 준다 |
   | 토키 박스 · 카트 교체 | 꾸미기 효과(재미용 1포인트) |
   | 돌 찾기 · 돌 던지기 · 백 슬라이드 · 죽은 척 | 원작처럼 작은 고정 피해, 위기 탈출(카이팅), 초보자 긴급 회피 |
3. ~~**제작(블랙스미스 제련 스킬)**~~ — **사용자 결정으로 제외** (2026-10-08: "블랙스미스는 제외해도 상관없어. 메커니즘이 이 게임이랑 안 맞아서."). 블랙스미스 스킬은 지금 그대로 둔다. 제작·제련 스킬과 새 블랙스미스 스킬은 넣지 않는다.
4. **설치형·지속 스킬**(파이어 월, 세이프티 월, 생츄어리, 덫, 베놈 더스트, 콰그마이어, 아이스 월)은 지면 장판을 새로 만든다. 시각 효과는 기존 renderer 스타일(굵은 외곽선, 평면색)을 따른다.
5. **이도류(어새신 좌우손 수련)**: 보조 손 무기 슬롯을 새로 만든다. 왼손 피해는 원작 비율로 계산하고 수련으로 오른다.
6. **페코 탑승(기사)**: 탑승 시 이동 속도 증가, 창의 중형 보정 100%, 무게(물약) 보너스. 탑승 상태가 외형에 보이는 것은 2단계(아트)로 미룬다.
7. **AI**: 새 스킬마다 auto 역할(attack / aoe / buff / heal / cc / support)을 정해 파티 AI가 알맞게 쓰게 한다. 설치형은 몰이 상황에서, 디버프(디크리스 AGI, 렉스 에테르나)는 보스·정예에게 쓴다.
8. **기존 세이브**: 스킬 id가 바뀌거나 사라지면 투자한 포인트를 돌려준다(마이그레이션).

## 2. 추가 스킬 (2단계, 원작에 없음)

- 1단계를 끝낸 뒤 빌드 비교(`npm run build-check`)에서 약한 빌드에 맞춰 더한다.
- → 빌드마다 특화 스킬 하나(대표 빌드는 둘)로 정리해 넣었다: `SKILLS_META.md` (2026-10-09). 속성 전환·마력 부여·성역의 오라·숨 고르기가 여기 들어갔고, 채굴(광석 사냥꾼)은 전투 빌드가 아니라 빠졌다.

## 4. 구현 상태 (2026-10-08, 1단계)

### 4.1 들어간 것
- **스킬 트리**: 블랙스미스를 뺀 12직업을 rAthena pre-re `skill_tree` 그대로 맞췄다 (최대 레벨·선행 조건·퀘스트 스킬 포함). 수치는 RateMyServer pre-re 기준이고, 시전·딜레이만 방치형 속도에 맞춰 대략 절반으로 줄였다.
  - 개수(원작 / 이 게임): 초보자 3, 검사 10, 마법사 14, 궁수 7, 성직자 15(+성스러운 일격), 도둑 10, 상인 10, 기사 11, 위저드 14(+마력 수련·증폭), 헌터 18, 프리스트 19, 어새신 12(+그림자 걸음). 블랙스미스 7은 그대로.
  - 퀘스트 스킬은 스킬 포인트 없이 배운다: 1차 직업 레벨 35 + 3,000z, 2차 직업 레벨 40 + 12,000z (초보자 죽은 척: 직업 레벨 7). 스킬 창의 「퀘스트」 버튼.
  - 원작과 다른 이름 규칙: 새 스킬은 모두 오리지널 한국어 이름이다. 예전부터 있던 블리츠 비트·앵클 스네어·클레이모어 트랩·아드레날린 러쉬는 그대로 두었다.
- **스킬 슬롯 (사용자 요청)**: 동료마다 액티브 슬롯 6칸. 자동 AI는 슬롯에 넣은 스킬만 쓴다.
  - 공격 스킬은 왼쪽 슬롯부터 우선. 광역 스킬은 몹이 모여 있을 때만, 힐은 불사에게 공격으로도 (슬롯 자리 순서대로).
  - 힐·버프·부활·디버프·설치 스킬은 슬롯에 있으면 각자의 조건에 따라 쓴다. 패시브는 슬롯 없이 늘 적용.
  - 카드로 얻은 스킬(힐 Lv1 카드 등)과 장비 발동 효과(M5)는 슬롯 없이 그대로 동작한다.
  - 새로 배운 액티브는 빈 슬롯을 자동으로 채운다. 스킬 창 위의 슬롯 6칸을 눌러 고르거나 비우고, 줄마다 「슬롯 넣기/빼기」. 「슬롯 자동 채우기」는 빌드 스킬 → 쓸 만한 순서로 다시 채운다.
  - 예전 스킬별 자동 켜기/끄기(`AutoConfig.skills`)는 슬롯으로 바뀌었다 (켜져 있던 액티브를 좋은 순서로 6칸에).
- **설치 효과 시스템** (`world.grounds`, 그리기 `src/render/grounds.ts`): 화염벽, 수호벽, 장막, 성역, 대퇴마(결계), 폭풍한설, 늪, 독 안개, 얼음 벽(몬스터를 막는 블록), 화염 기둥, 헌터 덫 9종, 말하는 상자. 시전자당 개수 제한(원작처럼 오래된 것부터 사라짐).
- **상태이상**: 석화(땅속성·DEF −50%·HP 감소), 수면(맞으면 깸), 침묵(몬스터 스킬 봉인), 속박(앵클 스네어: 이동만 막음), 속도 감소(AGI·이속), 늪(AGI·DEX −10%/레벨, 이속 −50%), 성호(DEF −%), 영원의 율법(다음 피해 두 배 — 한 스킬의 모든 타격). 빙결·석화는 원작처럼 피해를 받으면 깨진다(얼린 스킬·그 스킬의 남은 타격까지는 유지). 중독 몹은 DEF −25%.
- **수련 공격력**: 한손검·양손검·창·카타르·둔기 수련, 악마 퇴치, 짐승 사냥은 원작처럼 방어 뒤에 더하는 고정 공격력. 신의 가호는 불사·악마에게 받는 피해를 고정으로 줄인다. 천사의 가호는 VIT 방어 %.
- **원작 메커니즘**: 반격(자세 → 근접 한 번 막고 방어 무시 크리 반격), 회전 강타(선행: 강타 10·폭렬검 3·양손검 수련 5·양손검 가속 10·반격 5), 탑승(이속 +25%, 창 중형 100%, 공속 절반 → 기병 수련), 창 휘두르기는 탑승 중에만, 수호의 장막은 한 명·타수 제한, 축복·속도 증가·성스러운 손길은 한 명씩, 정화(불사 즉사 확률·실패 시 성 피해), 대퇴마는 불사·악마만, 유성우는 유성 2~7개 × 1~5타, 폭풍한설은 0.5초마다 최대 10타·3타째 빙결, 물의 구는 물가에서만 연타, 이도류(어새신 방패 칸에 단검·한손검·도끼, 오른손 50+10%·왼손 30+10%/레벨, 공속 원작식), 은신 이동 중 그림자 송곳니, 독 반격·독 폭발, 매(LUK×0.3% 오토 블리츠, 강철 발톱 +6/레벨).
- **숨는 몬스터**: 좀도둑 벌레, 그림자 두목, 유령등불, 갱도 망령, 모래 망령, 촛불 망령은 다치면 5초 숨는다. 탐지의 불·성광(성 피해 145%)·탐지·집중력 향상·대지 진동이 드러낸다.
- **촉매**: 푸른 마석·붉은 마석·덫·돋보기는 도구 상점, 성수는 성수 만들기, 돌멩이는 돌 줍기. 촉매가 없으면 그 스킬은 쓰지 않는다.
- **세이브 마이그레이션** (`state.ts migrateSkills`, `skillsV: 2`): 사라진 스킬·최대 레벨 초과분은 포인트 환불, 퀘스트 스킬이 된 것(모래 뿌리기·성스러운 빛·카트 돌진)은 포인트를 돌려주고 Lv 1로 유지. 원작 선행 조건이 안 맞으면 남은 포인트로 선행을 먼저 사 주고, 모자라면 그 스킬을 환불. 처음 켤 때 한 번 알림.

### 4.2 유틸 스킬 방치형 규칙 (§0 표를 이렇게 구현)
| 스킬 | 구현 |
|---|---|
| 순간이동 | Lv1: 근처(약 380px)에 사냥감이 없으면 파티가 다른 몹 곁으로. Lv2: 위험 몹이 150px 안이면 순간이동으로 따돌림 (6초 재사용) |
| 차원문 | 퀵슬롯 HP 물약이 바닥나면 마을로 → 자동 사냥 퀵슬롯 소모품을 30개까지 구입 → Lv2+는 2.5초 뒤 기억한 사냥터로 귀환 |
| 노점 | 장비 판매가 +3%/레벨 (파티 공유, 바가지와 곱) |
| 감정 | 몬스터가 떨군 희귀·전설 등급은 미감정(옵션 ???, 착용 불가). 파티에 감정을 익힌 상인이 있으면 줍는 즉시 감정, 없으면 장비 정보에서 돋보기(40z)로 |
| 무게 증가 | 파티 퀵슬롯 물약 회복 +1%/레벨, 카트 돌진 +10%/레벨 |
| 탐지의 불 · 성광 · 탐지 · 집중력 향상 | 숨은 몹을 드러냄 (성광은 성 피해) |
| 간파 | 몬스터 정보에 크리 저항·면역·숨기·스킬 수를 보여 주고, 못 잡은 위험 몹의 정체도 드러냄 |
| 화살 제작 | 스킬 창에서 잡템 → 속성 화살통 (반딧불 가루 → 불, 물먹은 젤리·서리 핵 → 물, 조약돌·바위 껍질 → 땅, 민들레 솜털·눈보라 결정 → 바람, 요정의 이슬 → 성) |
| 성수 만들기 · 돌 줍기 | 싸움이 없을 때 성수 10병, 돌 5개까지 채움 |
| 뒤로 구르기 | 근접 몹에 물린 후열이 걷는 대신 5칸 굴러 물러남, HP 30% 아래에서 둘러싸이면 탈출 |
| 죽은 척 · 하이딩 | HP가 낮을 때 몬스터를 떼어 내고 회복되면 나옴 (하이딩은 곤충·악마·보스에게 들킴) |
| 이동 중 회복 | 원작처럼 걷는 동안 HP 자연 회복이 멈추고, 이 스킬이 절반을 살림 |
| 인내 | 몬스터 7타까지, MDEF +레벨, 시전 밀림 없음 (방치형: 받는 피해 −레벨%) |
| 충격파 덫 | 몬스터는 SP가 없어서 스킬 재사용 대기를 늘림 |
| 용수철 덫 · 덫 회수 | 덫이 몇 칸 앞에서 터짐 · 시간이 다 된 덫 재료를 돌려받음 |
| 카트 교체 · 말하는 상자 | 꾸미기: 상인 뒤에 손수레(꽃무늬), 카드가 나오면 상자가 외침 |

### 4.3 남은 것
- 블랙스미스 제작·제련 — **사용자 결정으로 제외**.
- 탑승한 기사의 외형(질주새)은 아트 단계로.
- 원작의 "스킬 = 한 덩어리 피해"는 타격마다 처리한다. 영원의 율법·빙결 깨짐은 한 스킬의 타격 묶음을 하나로 본다.
- 조정 메모 (5분 build-check, 망자의 동굴): 성스러운 일격(2단계 스킬)이 둔기 수련과 겹쳐 철퇴 사제가 1,092/h까지 올라 SP 6+2×레벨, ATK 100+20×레벨%로 낮췄다(600/h). 매 공식을 원작(강철 발톱 ×6, LUK×0.3)으로 바꾼 만큼 매 정체성 아이템 3종의 오토 블리츠·블리츠 피해를 올렸다.
