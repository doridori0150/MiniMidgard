> 근거: `BUILD_TREE.md`(빌드 40개), 사용자 결정.

> - "디아블로처럼 아이템 상위 티어를 계속 확장해서 DPS가 점점 높아지고, 대균열 같은 콘텐츠."

## 0. 한 장 요약

| 층 | 목표 | 언제 |
|---|---|---|
| 1. 상성 축 | 빌드마다 **강한 상대·약한 상대**가 분명하다. 어디서나 최강인 빌드는 없다 | 지금부터 |
| 2. 동료 명단 | 동료를 최대 9명까지 모으고, 출전은 3명. 상대에 맞춰 고른다 | 2차 전직 무렵 |
| 3. 균열 | 단계가 끝없이 오른다. 단계마다 규칙(속성 편중·고방어·반사·떼…)이 붙는다. 진행 바 → 균열 수호자 → 제한 시간 | 2차 전직 + Lv 60 |
| 4. 장비 티어 | 균열 장비: 단계가 높을수록 기본치와 랜덤 옵션이 오른다. 고대·태초 등급 | 균열과 함께 |
| 5. 카드 티어 | 같은 카드 3장 → ★2 → ★3(새 메커니즘 줄) + 균열 전용 카드 | 균열과 함께 |
| 6. 환생 | Lv 99·Job 50 → 상위 직업으로 다시. 스탯 보너스, 장비·카드 유지 | 균열 40단계 무렵의 벽 |

## 1. 상성 축 (빌드 프로필 × 몬스터 특성)

빌드마다 다섯 축의 값을 둔다. 몬스터와 균열 규칙은 그 축을 시험한다.

| 축 | 값 | 시험하는 몬스터 특성 · 균열 규칙 |
|---|---|---|
| 피해 | 물리 / 마법 / 고정(블리츠·덫·독·금화) | **강철**(DEF↑↑: 물리 약화) · **반사**(마법 반사) · **결계**(고정 피해 −50%) |
| 명중 | DEX / 크리(회피 무시) / 필중(마법·고정) | **안개**(HIT −40) · **날쌘 무리**(FLEE↑↑) · **급소 보호**(크리 저항 +50%) |
| 범위 | 단일 / 광역 | **떼**(작고 약한 몹이 3배) · **거인**(큰 몹 소수, HP↑↑) |
| 상성 | 속성·종족·크기 | **원소 편중**(전부 한 속성) · **불사 행렬** · **무형**(독 무효) · **대형만** |
| 생존 | 회피 / 체력 / 회복 | **포위**(몰이 패널티 2배) · **저주받은 땅**(회복 −50%) · **맹독 안개**(지속 피해) |

- `BuildDef.profile`
  - `dmg: 'phys' | 'magic' | 'fixed'`
  - `hit: 'dex' | 'crit' | 'sure'`
  - `area: 'single' | 'aoe'`
  - `survive: 'dodge' | 'hp' | 'heal'`
  - `tags: string[]` — 예: '불사 특효', '독', '대형 약함'
- **빌드 카드**: "강한 상대 / 약한 상대" 칩이 프로필에서 자동으로 나온다.
- **몬스터 상세·맵 상세**: "이 상대에 강한 빌드" 칩이 붙는다.
- **균열 진입 화면**: "이번 규칙에 맞는 출전 추천"이 뜬다.

## 2. 동료 명단

- 영입 상한: 3 → 최대 9.
  - Lv 40, 2차 전직, 균열 10·20·30단계… 마다 1칸씩 늘어난다.
- **출전 3명.** 왼쪽 초상화 3칸이 출전 중인 동료다. 명단은 동료 팝업의 "명단" 칸에 있다.
- **대기 동료**: 출전 파티가 얻는 경험치의 25%를 함께 받는다("훈련"). 교체해도 손해가 크지 않다.
- **교체는 마을에서만, 언제든.** 균열 진입 화면에서 바로 바꿀 수도 있다.
- **목표**: 물리·마법·고정, 단일·광역, 회피·체력 빌드를 고루 키우는 것이 균열 고단계의 조건이 된다.

## 3. 균열 (대균열 + RO)

- **입장**: 마을의 "균열 관리인"(NPC). 2차 전직 + Lv 60에 열린다. 단계 1부터 시작한다.
- **한 판의 구성**
  1. 기존 테마 키트로 맵을 만든다. 몬스터 풀은 단계 구간(1~10, 11~20, …)마다 전 지방의 몬스터에서 섞는다. 정예 무리도 나온다.
  2. **규칙 1~2개**가 무작위로 붙는다(1장 표). 10단계마다 고정 규칙 하나가 더 붙는다.
  3. 처치로 **진행 바**를 채운다. 정예는 많이 채운다. 다 차면 **균열 수호자**(MVP 변형, 규칙 적용)가 나온다.
  4. **제한 시간 10분**(방치형이라 D3의 15분보다 짧다). 수호자를 잡은 시간에 따라 다음 단계가 +1/+2/+3 열린다. 실패하면 다음 판은 같은 단계다.
- **난이도 곡선**: 단계마다 몬스터 HP ×1.12, ATK ×1.08. 대략 20단계마다 장비 한 티어가 필요하다.
- **방치형 규칙**
  - 자동 재도전 옵션: "최고 단계 도전 / 한 단계 아래에서 파밍".
  - 오프라인 중에는 균열이 진행되지 않는다. 현재 사냥터 파밍만 된다.
- **보상**
  - 균열 장비(4장). 단계가 높을수록 티어와 옵션이 오른다.
  - **균열 정수**(재화): 카드 각성(5장), 재련(옵션 다시 굴리기).
  - 수호자 카드(균열 전용 상위 메커니즘 카드).
  - 단계별 첫 클리어 보상.
  - **최고 기록판**: 내 최고 단계와 그때 출전한 3인 조합이 남는다.
- **주간 시즌**(선택): 주마다 "이번 주 고정 규칙"이 바뀐다. 메타가 계속 바뀐다.

## 4. 장비 상위 티어 (디아블로식)

RO 장비의 고유 이름과 슬롯은 그대로 둔다. 그 위에 **등급과 아이템 레벨**을 얹는다.

| 등급 | 어디서 | 랜덤 옵션 | 기본치 |
|---|---|---|---|
| 일반 | 상점·필드 | 0 | 기본 |
| 고급 | 필드 드랍 일부 | 1 | 기본 |
| 희귀 | 필드 보스·던전 | 2 | +5% |
| 전설 | 정체성 아이템(BUILD_TREE §3) | 고유 효과 + 1 | +10% |
| 고대 | 균열 전용 | 고유 효과 + 3 | +30% |
| 태초 | 균열 70단계 이상, 극히 드묾 | 3 (최대치) | +50% |

- **아이템 레벨**: 균열 단계가 높을수록 기본 ATK·DEF와 옵션 수치가 오른다. DPS가 계속 오른다.
- **옵션 풀**: 기존 `Bonus` 필드에서 뽑는다.
  - STR~LUK, ATK %, 종족·크기·속성 %, 크리, 크리 피해, 공속, 시전 −, 명중·회피, HP %.
  - **직업 스킬 피해 %**(M12), 발동 효과(M5).
- **재련**: 균열 정수로 옵션 하나를 다시 굴린다.
- **정련**: 그대로(+10까지). 고대·태초는 정련 실패 시 사라지지 않고 −1로 떨어진다.
- 저장 형식: `EquipInst`에 `grade`, `ilvl`, `opts: Bonus[]`를 더한다. 기존 장비는 일반 등급이다.

## 5. 카드 상위 티어와 메커니즘

1. **각성**
   - 같은 카드 3장 + 균열 정수 → ★2(효과 ×1.5), ★2 3장 → ★3(효과 ×2 + **각성 줄** 하나).
   - 예: 꿀벌 병정 ★3 = 크리 +18, **크리 시 공속 +10%(3초)**.
2. **새 메커니즘 카드** (균열 수호자·고단계 정예 드랍)
   - **조건부**: "HP 50% 이하일 때 ATK +30%".
   - **중첩**: "적중 시 ATK +1%, 최대 20중첩".
   - **속성 전환**: "공격이 상대의 약점 속성으로 바뀐다".
   - **연쇄**: "처치 시 주변에 폭발".
   - **세트**(M9): 같은 던전 카드 2~4장을 함께 끼면 추가 효과.
3. **MVP 카드 각성**: MVP 카드 ★2·★3이 균열 고단계의 핵심 목표가 된다.

## 6. 환생

- 조건: Lv 99 · Job 50.
- 결과: 상위 초보자 → 상위 1차 → 상위 2차. 이름만 바뀐 상위 직업이고 상위 스킬은 2단계에서 다룬다.
- 보너스: 스탯 포인트 +25%, HP·SP +25%. 장비·카드·명단은 유지한다.
- 균열 40단계 무렵 벽의 해답이 된다.
