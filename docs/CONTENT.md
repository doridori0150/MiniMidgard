## 1. 설계 규칙

1. **맵 선택 = 목적 선택.** 같은 레벨대(밴드는 8~12레벨씩 겹침)에 **경험치 맵**과 **득템 맵**이 따로 있고, 속성 숙제가 다르다.
   - 경험치 맵: 비선공·밀집·한두 속성 위주(무기 하나로 해결). 몬스터 `expMul` 1.0(골렘류 1.1).
   - 득템 맵: 속성이 섞이고 선공이 많다. `expMul` 0.85~0.9 대신 장신구·머리 장비·[n] 슬롯 장비·광석이 나온다.
   - 던전 층: 1층 경험치/광석 → 아래층 득템 → **MVP는 최하층**. 층 보스(필드 보스)가 다음 층을 연다.
   - 숨겨진 장소: `expMul` 1.0~1.1 + 고유 외형·장신구·카드 + 카드율 0.4%.
2. **해금 사슬**: `unlockBy` 맵의 필드 보스를 처음 잡으면 열린다. 지방 입구 보스가 다음 지방을 연다 — 불사 동굴(망자의 동굴)은 **곁길**이 되어 성직자 없는 파티도 막히지 않는다.
   ```
   햇살 평원(뿔토끼 대장) ─┬─ 네잎 언덕
                           ├─ 물레방아 수로(수로 쥐왕) ── 수로 깊은 곳[MVP 말랑 대왕]
                           └─ 속삭이는 숲(은빛 늑대왕) ─┬─ 깊은 숲
                                                       ├─ 고목의 심장[MVP 고목 정령]
                                                       └─ 잿빛 채석장(채석장 거인) ─┬─ 버려진 광산 1층(해골 십장) ── 망자의 동굴(해골 기사) ── 망령의 갱도[MVP 망령 군주]
                                                                                   ├─ 신기루 오아시스
                                                                                   └─ 작열하는 사막(전갈왕) ─┬─ 피라미드 1층(붕대 대신관) ── 피라미드 지하[MVP 모래의 파라오]
                                                                                                            ├─ 빙하 협곡
                                                                                                            └─ 얼어붙은 설원(설원의 군주) ── 얼음 동굴(서리 비룡) ── 얼음 동굴 심층[MVP 서리 마녀]
   숨겨진 장소: 말랑말랑 왕국 · 달그림자 오솔길 · 봉인된 광맥 · 모래에 묻힌 신전 · 별이 잠든 호수 (3장 참고)
   ```
3. **드랍 테이블 모양(RO식)**: 고유 잡템 40~60% · 두 번째 잡템/음식 · 소비템 2~12% · 장비 0.1~0.6%(가끔 더 드문 [n] 슬롯판) · 특정 중반 몬스터의 광석 · 카드. 몬스터마다 **자기 잡템이 하나씩**(가장 많이 떨구는 몬스터) — 모자 장인 레시피 재료로 쓰기 좋다. 초반 몬스터도 장난스러운 슬롯 무기를 떨군다(말랑 → 나이프[3], 조약돌 골렘 → 메이스[3], 해골 광부 → 배틀 액스[3], 수로 쥐왕 → 카타나[3]).
4. **광석 맵**: 별철·수호석은 버려진 광산 1층(해골 광부·광석 말랑, 1000킬당 ~7개), 봉인된 광맥(~18개), 깊은 숲 그루터기(수호석), 얼음 동굴(~7개). 보스는 25~100%.
5. **카드율**: 시뮬로 맵별 시간당 처치 수(파티 400~2000킬/h, 종당 150~350킬/h)를 재고, 맵 하나를 지나가는 동안 그 맵 카드가 몇 장 나오게 맞췄다. 경험치 맵 0.25% · 던전 0.3% · 득템 맵 0.35% · 숨겨진 장소 0.4% · 필드 보스 2% · 숨겨진 장소 보스 3% · MVP 4% · 여우불(염 갑옷) 0.15%.
6. **카드 슬롯 규칙**: 무기 = 종족·크기·속성 % / ATK / 크리 / 속성 부여, 갑옷 = HP·VIT·갑옷 속성, 방패 = 종족 피해 감소, 걸치기 = 속성 저항·FLEE·무속성 감소, 신발 = AGI·HP·SP, 액세서리 = 스탯·회복·스킬 부여, 머리 = INT·DEX 등. **같은 분류(종족끼리·크기끼리·속성끼리)는 더하고 분류끼리는 곱한다** → 종족 카드 + 크기 카드를 섞어 꽂는 것이 같은 카드 겹치기보다 세다. 대가가 붙은 카드(선인장·그루터기·트롤·채석장 거인·여우불·유령등불·달토끼·말랑 여왕)는 연구거리.
7. **속성 숙제(지방별)**: 평원 = 물·땅(바람/불), 수로 = 물(바람), 숲 = 땅·바람 섞임, 채석장·광산 = 땅·무형(불), 동굴 = 불사·염(성·불·속성 공격), 사막 = 불·땅(물/불), 오아시스 = 땅·물·바람 셋, 피라미드 = 불사·곤충, 설원 = 물(바람), 빙하 협곡 = 물 + 바람(바람 무기 하나로는 막힘), 호수 = 성(암흑) + 바람(땅). 숨겨진 장소의 보스 둘(태양의 신관·호수의 파수꾼)은 **성속성**이라 성직자 공격이 안 통하고 암흑 부여(뿔 말랑 카드)가 답이다.

### 3.1 말랑말랑 왕국 — "말랑이를 수백 마리 터뜨려 본 사람만"
- **소문(hint)**: 말랑이를 수백 마리 터뜨려 본 사람만 듣는다더라. 수로 밑바닥 왕관 쓴 말랑이 무지개 너머를 지킨다고.
- **단서** `q_rainbowdrop` 무지갯빛 물방울 (말랑 0.2%, 독말랑 0.2%, 물먹은 말랑 0.4%): "말랑이 몸속에서 나온 무지갯빛 방울. 수로 밑바닥 쪽으로 기울며 흔들린다. 거기 사는 커다란 말랑이 무언가를 알고 있는 걸까?"
- **조건**: ① 말랑 300마리 처치 (또는 물방울을 주우면 먼저 발견) → ② 말랑 대왕(수로 깊은 곳 MVP) 처치.
- **발견 경로**: 햇살 평원에서 1시간쯤 사냥하면 물방울이나 처치 수로 지도에 "?"가 뜬다(시뮬: 17분째 물방울로 발견) → 소문이 "수로 밑바닥 왕관 쓴 말랑"을 가리킴 → 수로 쥐왕 → 수로 깊은 곳 → 말랑 대왕 처치(Lv 25 MVP) → 열림(시뮬: 파티 3.4~7.3시간째, 솔로 16시간째).
- **열릴 때**: 말랑 대왕이 쓰러진 자리에 무지개 웅덩이가 일렁인다… 말랑말랑 왕국으로 가는 길이 열렸다!
- **보상**: 잡기 쉬운 말랑이 가득한 경험치 맵(최대 13마리), 말랑 모자 최다 산지(무지개 0.12%, 날개·뿔 말랑 0.2%, 여왕 8%), 말랑 홍조, 말랑 반지[1], 성 갑옷 카드(날개 말랑), 암흑 부여 카드(뿔 말랑), 필드 보스 말랑 여왕(블레싱 부여 카드), 성의[1].
- **점술가 3단(제안)**: "말랑이를 더 터뜨려 보거라." → "물 밑의 왕을 쓰러뜨린 자에게 무지개가 보인다." → 체크리스트 원문.

### 3.2 달그림자 오솔길 — 밤에만 열리는 숲길 (리서치 5.1 안 채택)
- **소문**: 밤이 되면 숲의 늑대들이 한쪽으로만 운다더군. 달이 높을 때 말이야.

## 4. 어디서 파밍하나

### 4.1 장신구·머리 장비 (찾아가는 맛)

### 4.3 방어구 요약
- 갑옷: 면 셔츠[1](애벌레) → 가죽 재킷[1](수로 쥐) → 모험가 슈트[1](동전벌레) → 나무 갑옷[1](그루터기) · 맨틀[1](큰버섯) → **곰가죽 갑옷**(꿀곰, 모든 직업 Lv 26) · 체인 메일[1](좀비) · 성의[1](날개 말랑) → 플레이트[1](해골 기사) → 2차 직업 갑옷[1](사막·설원 몬스터와 보스).

- 신발: 샌들[1](뿔토끼) → 신발[1](뿔토끼 대장) → 부츠[1](송곳니 박쥐·해골 사냥개) → 그리브[1](사막 자칼·서리 박쥐·모래사자).

## 6. 밸런스

### 6.1 규칙
- **몬스터 스탯 곡선**: HP(보정 전) ≈ 1.6·Lv², 평균 ATK ≈ Lv·(1.6 + 0.045·Lv). 골렘·트롤은 HP ×1.2~1.6, 정령·박쥐는 ×0.8. `tools/audit.ts curve`가 곡선에서 크게 벗어난 몬스터를 표시한다.
- **보스 HP**: 필드 보스 ≈ 같은 레벨 일반 몬스터의 12~17배, MVP 35~45배. 은빛 늑대왕은 37배였고 늑대 3마리를 15초마다 불러 솔로에게 벽이었다 → 11000 HP(19배), 늑대 2마리·20초·HP 85% 이하에서만.
- **경험치**: `mob()`의 레벨 곡선은 그대로 두고 전역 손잡이 두 개를 추가했다 — `EXP_RATE = 0.9`(베이스), `JOB_RATE = 0.66`(직업, 이전 0.78). 맵이 여러 장이 되자 파티가 항상 제 레벨 몬스터를 잡게 되어(이전 단일 사다리에서는 맵을 넘어서 버린 채 사냥) 레벨은 ~10%, 2차 전직은 ~20% 빨라졌기 때문이다. 그 위에 맵 역할로 조정: 득템 맵 ×0.85~0.9, 숨겨진 장소 ×1.0~1.1, 골렘 ×1.1, 보스 ×22, MVP ×70.
- **정련 재료 수급**: 별철·수호석은 광석 맵(광산 1층 ~7/1000킬, 봉인된 광맥 ~18/1000킬)과 보스(25~100%)가 주 공급원, 일반 맵은 0~3/1000킬.
- **돈**: 맵별 기대 수입(잡템 판매 + 장비 판매가)은 `tools/audit.ts maps`. 동전벌레(녹슨 동전 220z)가 초반 돈 맵 역할. 득템 맵은 잡템 단가가 아니라 장비·장신구 드랍으로 번다.
- **카드**: 6.2의 시뮬에서 30시간 동안 파티 75~83장(이전 28~46장) — 맵 하나를 지나는 동안 그 맵 카드 1~8장, 같은 카드는 대개 1~3장.

## 8. 엔진·UI 후속 작업 (메인 세션)

1. **세이브 이전**: 불러올 때 `unlockBy` 맵의 필드 보스를 이미 잡았으면(`progress[unlockBy].bossKills > 0`) 그 맵을 `unlocked`에 넣기 — 안 하면 기존 플레이어가 뿔토끼 대장·은빛 늑대왕을 다시 잡아야 새 맵이 열린다.
2. **스킬 부여 카드**: `items.ts`의 `CARD_SKILLS`(달토끼 → 힐 Lv1, 말랑 여왕 → 블레싱 Lv1). `world.ts` `enabledSkills`가 장착 카드의 스킬을 (보유 레벨과 큰 쪽으로) 합치면 된다. 그 전까지 두 카드는 대가(SP −10% / HP −5%)와 부가 효과(힐량 +10% / LUK +2)만 적용된다.
3. **월드맵**: 핀 24개 — `region`으로 묶어 지방 핀 → 맵 목록 시트를 추천. `render/worldmap.ts`의 지역 색은 지금 `theme`으로 칠하므로 채석장(`theme: 'desert'` + 회색 `tint`)이 광산 옆에 모래색 얼룩을 만든다 → `region` 기준으로.
4. **`tint`**: `#rrggbb` 문자열. 배경 위에 25~35% 알파로 덮는 것을 가정했다(수로 = 청록, 피라미드 = 사암, 광맥 = 보라, 호수 = 밤하늘).
5. **새 ZoneDef 필드**(선택): `role`(exp·loot·ore·zeny·mvp 태그)과 `specialty`(특산품 아이템 id 3개) — 지도 카드의 '특산' 표시용(리서치 #6).
6. **MVP 게이지 없는 맵**: 이제 필드 맵 대부분은 `mvp` 없이 `mvpGauge: 0`, 득템 맵은 보스도 없이 `bossGauge: 0` — 게이지 UI를 숨겨 주세요.
7. **전멸 후퇴**: `recoverWipe`는 `ZONES` 순서의 이전 맵으로 간다. 진입 레벨 순으로 정렬했지만, "같은 지방의 더 낮은 맵 → 없으면 레벨이 더 낮은 맵"이 더 자연스럽다(숨겨진 장소로 후퇴하지 않게).
8. **밤길 오프라인**: 달그림자 오솔길(20~2시)에서 접속을 끊으면 12시간 내내 그 맵 처리 — 창 안 시간만 그 맵, 나머지는 속삭이는 숲으로(리서치 4.2).
9. **렌더러(선택)**: 말랑 여왕에 왕관(`drawMob(..., crown)`), 새 종의 고유 스프라이트 후보 — 여우(월광 여우), 게(오아시스 게), 선인장(선인장 병정), 새(없음), 수정 골렘 반짝임.
