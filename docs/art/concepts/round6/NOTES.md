# ‘약간 도트 느낌’의 해석 — 생성 전 기록

라운드 5의 얼굴, 가는 갈색 선, 섬세한 회화적 채색과 의상 디자인을 유지한다. 바꾸는 것은 인체를 약 3.5등신으로 낮추는 것, 게임 크기에서 윤곽과 주요 명암에 약한 픽셀 격자감을 더하는 것, 걷기·공격의 동작 수를 늘리는 것뿐이다. 배경과 HUD 디자인은 라운드 5를 따른다.

도트 강도 비교는 동일한 쿠키 자세를 머리부터 발까지 약 80px 높이로 표시하고, 각 결과를 최근접 보간으로 정확히 3배 확대한다. 없음은 부드러운 축소와 원래 색조를 유지한다. 약함은 80px 격자의 윤곽과 작은 색면이 보이되 머리·얼굴·직물·금속의 회화적 명암을 남긴다. 중간은 더 큰 픽셀 군집과 줄어든 색 단계로 차이를 보여준다. 검은 외곽선, 무작위 디더링, 얼굴의 잡티, 전면적인 복고풍 재디자인은 사용하지 않는다.

세 강도의 최종 선택은 사용자에게 남긴다. 이번 모션과 필드의 작업 기준은 의뢰서가 허용한 ‘약함’으로 잡는다.

걷기는 8장, 공격은 8장으로 제작한다. 모든 프레임에서 오른쪽 3/4 방향, 해부학적 오른손의 검, 같은 얼굴·머리·의상·신체 축척을 유지한다. 걷기 전반과 후반에서 앞서는 다리를 교대하고 먼 팔은 가슴 앞을 가로지르지 않는다.

# 실제 도트 비교 방식

`r6_dot_strength.png`의 NONE / LIGHT / MEDIUM은 각각 없음 / 약함 / 중간이다. 동일한 생성 원화의 쿠키 대기 자세로 비교하므로 얼굴이나 자세가 바뀌어 생기는 차이가 아니다. 위쪽은 머리부터 발까지 80px, 아래쪽은 같은 픽셀을 가로·세로 각각 3배로 복제한 240px 표시다.

- 없음: Lanczos 축소, 원래 RGB 색조 유지.
- 약함: 면적 평균으로 약 80px에 축소하고 적응형 96색으로 정리. 디더링 없이 회화적인 명암과 색면을 남긴다.
- 중간: 40px에서 적응형 48색으로 정리한 뒤 최근접 보간으로 80px에 표시. 더 큰 픽셀 군집의 효과를 비교한다.

모든 3배 확대는 최근접 보간이다. 없음도 80px 이미지이므로 확대하면 픽셀이 보인다. 비교 대상은 ‘픽셀 존재 여부’가 아니라 원화의 부드러운 축소, 약한 색면 정리, 더 큰 도트 군집의 차이다. 원화에서 곧바로 최근접 축소한 초안은 검과 얼굴의 경계가 거칠어져 채택하지 않았다.

# 산출물과 재현 정보

라인업·필드·모션 원화는 내장 `image_gen.imagegen`으로 제작했다. 실제 호출 프롬프트와 입력은 `PROMPTS.json`에 기록한다. `assemble.mjs`는 생성된 원화의 프레임 추출·크기 조정·기준점 정렬, 강도 비교, 번호 표시, PNG/GIF 인코딩을 담당한다. `FRAME_MANIFEST.json`에 원본 좌표와 기준선, 축척, 프레임 시간을 기록한다.

`r6_lineup.png`는 1536×1024이며 원본과 같은 쿠키→여성 마법사→남성 궁수→슬라임 순서다. 인체는 약 3~4등신 범위를 목표로 짧게 조정했다. 슬라임은 인체의 등신 비율을 적용하지 않고 기존 형태를 유지했다. 쿠키의 금발·파란 튜닉·은색 흉갑·붉은 허리천, 마법사의 보라색 로브·푸른 구슬 지팡이, 궁수의 녹색 후드·망토·활을 유지한다.

`r6_field.png`는 정확히 390×844다. 라운드 5를 편집 입력으로 사용해 지형, 인물 배치, HUD 구성과 위치를 유지하며 새 비율과 약한 도트 느낌을 적용했다. 생성 기반 편집이므로 배경·장식의 개별 붓터치까지 픽셀 단위로 동일한 것은 아니다. 실제 게임 실행 화면이 아닌 컨셉 목업이다. 필드의 도트 질감은 생성 모델이 적용한 시각적 대응이며, 캐릭터 외 배경에는 일괄적인 팔레트 축소를 적용하지 않았다.

`r6_attack.png`는 8장의 번호 붙은 가로 배열이다. 각 프레임의 기본 캔버스는 144×116이며 접지 기준은 y=102다. `frames/`에 1배와 3배 PNG를 함께 보관한다. 캐릭터 높이는 자세에 따라 약 76~81px이며, 칼을 머리 위로 든 프레임의 검 높이는 몸 높이에서 제외한다. 동일 원화 축척을 적용했으며 프레임별 전신 높이를 억지로 같게 늘이거나 줄이지 않았다.

`r6_attack.gif`는 432×348, 8프레임이다. 프레임 지속 시간은 50 / 50 / 40 / 60 / 70 / 80 / 90 / 140ms이며, 네 번째 타격 프레임은 정확히 140ms부터 시작한다. 준비→들어 올림→최대 준비→타격→후속 동작→정리→회수→대기의 순서다. GIF 인코딩 후 실제 타임스탬프와 8프레임 수를 ffprobe로 확인했다.

# 검수 및 보존

공격 8장을 원화와 게임 크기 배열에서 확인했다. 검은 같은 오른손에 있고 몸은 오른쪽 3/4 방향을 유지한다. 빈 먼 팔은 몸 뒤쪽으로 남는다. 생성 시트에서 이웃 칸으로 넘어온 검 끝 조각은 해당 캐릭터의 추출 영역을 분리해 제거했다. 얼굴과 발밑에는 추가 디더링이나 효과 입자를 넣지 않았다.

걷기 초안은 같은 다리가 앞서는 반복 문제가 있어 재제작했다. 상체만을 참조한 중간 시도는 장화 디자인까지 달라져 채택하지 않았다. 채택 여부와 수정 이력은 `PROMPTS.json`에 구분한다. 포즈 가이드는 이번 캐릭터의 걷기 다리 교대를 설명하기 위해 직접 만든 도식이며 외부 게임 이미지가 아니다.

최종 걷기는 포즈 가이드를 첫 번째 입력으로, 상체와 장화 디자인을 별도 참조로 사용해 다리 교대를 반영했다. 7번 프레임에 남은 청색 가이드 흔적은 이미지 편집으로 갈색 가죽으로 수정했다. 최종 원화 8장 및 축소 배열을 모두 육안 검수했다. 1~2번은 먼 왼발 선행, 3번은 발이 모이는 통과 자세, 4~6번은 가까운 오른발이 앞쪽으로 이동하며 선행, 7번은 반대 다리 통과, 8번은 먼 왼발을 다시 앞으로 내미는 자세다. 오른손 검, 오른쪽 3/4 몸 방향, 얼굴·머리·의상 색상은 모든 프레임에서 유지된다. 검과 가려진 팔 때문에 관절이 모두 드러나는 해부학 도해는 아니며, 다리 겹침과 발 위치로 교대를 읽는 컨셉 모션이다.

`r6_walk.png`와 `r6_attack.png`는 각각 3456×382의 가로 8장 배열이다. `r6_walk.gif`는 432×348, 8프레임, 장당 정확히 90ms로 총 720ms에 순환한다. 걷기 캐릭터는 약 81~83px 높이이며 3배 확대에서 약 243~249px이다. 두 동작 모두 144×116의 같은 기본 캔버스를 쓰고, 축소 과정의 반올림 오차를 최대 1px 수직 이동으로 정렬해 발의 실질 접지선을 y=102로 맞췄다. 각 동작 안에서는 하나의 공통 축척을 적용한다.

`node docs/art/concepts/round6/assemble.mjs`로 조립하고 `node docs/art/concepts/round6/verify.mjs`로 크기·8프레임 수·접지선·프레임 시간·잘림 여부를 재검사할 수 있다. 검사 결과는 `VALIDATION.json`에 저장한다. 생성된 프레임 사이에 미세한 선과 주름 차이는 남으므로 원화를 픽셀 단위로 복제한 리깅 스프라이트라는 뜻은 아니다.

작업 산출물은 이 `round6/` 안에만 기록한다. 라운드 5, `src/`, 브리프 등 다른 파일은 수정하지 않는다. 외부 게임의 스크린샷·원화·로고를 저장하지 않았으며 커밋·푸시하지 않았다. 이 보드는 컨셉 검토용이며 게임 런타임에는 연결하지 않았다.
