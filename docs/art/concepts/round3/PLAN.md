# Round 3 — 직업 의상·머리 컨셉 및 부품 분해 계획

## 이번 납품의 범위

`class_lineup.png`는 13직업 의상 승인용, `hair_faces.png`는 8개 머리 × 여성형·남성형 얼굴 승인용이다. 이번에는 컨셉 이미지와 계획만 만든다. 부품 PNG, manifest, 엔진 구현은 승인 후 별도 제작한다. 생성 방식과 정확한 입력 문구는 `PROMPTS.md`에 보존한다.

첫 줄은 초보자·검사·마법사·궁수·성직자·도둑·상인이다. 둘째 줄의 첫 칸은 비우고 기사·위저드·헌터·프리스트·어새신·블랙스미스를 대응하는 1차 직업 아래에 둔다. 얼굴은 읽는 순서대로 여성형·남성형을 번갈아 사용한다. 직업과 성별을 묶지 않으며 실제 제작에서는 모든 의상에 두 얼굴을 교환할 수 있다.

## 고정할 기존 계약

- 기준: `docs/art/rig-codex/manifest.json`과 `verify.py`, 승인된 `preview_assembled.png`. 기존 파일은 수정하지 않는다.
- 캔버스 384×320, 원점 `[148,286]`, 기준 높이 257, 표시 높이 80. 표시 배율은 `80/257`. 모자·무기·머리 꼬리의 돌출을 이유로 몸 전체를 직업마다 다시 축소하지 않는다. 몸의 기준 높이와 머리 크기를 공통으로 유지하고 돌출 부속의 범위만 따로 관리한다.
- body `[148,174]`, head 상대 오프셋 `[2,-7]`와 배율 `1.18`, 양 어깨 `[-27,6]` / `[29,8]`, 양 고관절 `[-17,59]` / `[17,59]`를 유지한다. 성별·갑옷·로브 때문에 팔다리 길이 또는 머리 크기를 바꾸지 않는다.
- idle은 기존 far arm 24°, near arm -32°, far leg 5°, near leg -5°가 기준이다. 활·창·지팡이의 길이에 맞춘 장비 각도는 별도 프로필로 제안하되 몸의 idle은 유지한다.
- 기존 노드의 부모 변환 × 앵커 이동 × 회전 × 배율, part pivot, 전신 좌우 반전, z 정렬, 숫자 보간과 slot 단계 전환 규칙을 그대로 쓴다. 접촉 팔은 어깨 pivot을 유지하는 대체 이미지이며 별도 팔 관절을 늘리지 않는다.
- 굵은 짙은 갈색 외곽선, 얇은 내부선, 기본색과 한 단계의 단단한 그림자만 사용한다. 작은 광택·그라데이션·직물 질감은 만들지 않는다. 소매는 어깨를, 몸통 밑단은 고관절을 덮으며 관절을 가로지르는 끈과 장식을 한 이미지에 그리지 않는다.

## 계약 확장 설계 — 아직 미구현

### 선택 슬롯과 레이어

`leg_near`, `leg_far`, `face`, `hair_front`, `hair_back`를 외형 선택에서 해석할 수 있게 확장한다. 현재 manifest에 `hairStyles`와 `faces` 목록은 있으나 `verify.py`의 해당 노드는 고정 part를 사용한다. 목록 추가만으로 교체가 구현되었다고 간주하지 않는다. 기존 기본값으로 렌더한 결과는 기존과 동일해야 한다.

의상별 선택 노드 `cape_back`, `quiver_back`, `scarf_back`, `robe_back`, `robe_front`, `apron_front`, `shield_far`, 모자 레이어를 추가한다. 사용하지 않는 부속은 명시적 null로 비활성화한다. 기본 다리 이미지는 교환하더라도 기존 고관절/foot 앵커를 유지한다.

예상 z 순서: 후면 긴 머리 10 → 망토·화살통·스카프 꼬리 15~19 → 로브 뒤 25 → far/near 다리 30/35 → 몸통 40 → far 팔 45 → far 방패 48 → 로브·앞치마 앞 50 → 얼굴 70 → 앞머리 80 → 일반 무기 85 → near 팔 90 → 주먹 위 카타르 94 → 모자 앞 100. 머리 부속과 기존 head_top/head_mid가 겹치면 모자 장비 프로필이 해당 장식의 표시 여부를 명시한다. 모자 뒤는 얼굴 뒤의 별도 z를 쓴다. 활 동작처럼 far 손이 앞으로 나오는 순간에는 기존 node.z override를 프로필에서 명시한다. 모든 조합을 하나의 고정 z로 해결하지 않는다.

### 로브·치마·앞치마

상반신 torso와 허리부터의 robe_front/back을 분리하고 하부는 body/waist 앵커에 붙인다. 다리를 숨겨도 발 움직임은 유지한다. 로브 앞·뒤는 같은 치맛단을 중복해서 그리지 않으며 두 겹의 외곽선이 겹치지 않도록 한다. 걷기는 작은 밑단 회전으로, sit/dead는 별도 접힌 하부 이미지로 대응한다. 판 하나를 그대로 눕혀 다리를 노출하거나 천이 몸을 가로지르게 하지 않는다. 긴 앞치마도 같은 방식을 쓰되 블랙스미스는 옆으로 부츠가 읽히게 한다.

### 망토·스카프·화살통

망토와 긴 스카프 꼬리는 body의 back/neck 앵커, 화살통은 back/waist 앵커에 붙인다. 팔이나 다리와 연결된 끈은 그리지 않는다. 어깨를 지나는 짧은 끈 부분만 몸통에 포함한다. 위저드 긴 머리와 망토의 순서는 별도 프로필로 확인하고, 헌터 화살통 상단은 어깨의 빈 공간을 침범하지 않게 낮춘다.

### 모자와 머리 가림

위저드 모자는 `hat_back`/`hat_front`로 분리한다. 단순히 불투명 모자를 올려 삐친 머리를 억지로 덮는 대신 각 머리에 `under_hat` 변형 또는 head-local 가림 마스크를 제공한다. top ahoge와 높은 묶음은 숨기고 관자·앞머리·낮은 뒷머리만 보인다. 표준 front/back pivot은 유지한다. 기본 모자 프로필에서는 head_top 장식을 비활성화하고 head_mid는 허용 목록만 노출한다.

### 방패와 카타르

방패는 far 팔의 새 `shield` 앵커를 따라가며 팔 회전/반전을 상속한다. weapon 슬롯을 차지하지 않는다. 공격 중 신체 또는 얼굴을 덮지 않는지 검사한다. 양손 무기를 쓸 때에는 방패를 숨기는 장비 프로필을 명시한다.

카타르는 arm_near의 `knuckle` 앵커에 붙는 주먹 장비다. 날의 장축이 손등/전완 방향을 따른다. 기존 무기의 절대 `worldAngle` -48°를 자동 적용하지 않는다. 프레임이 손을 감싸는 뒤쪽 mount와 주먹 앞 blade를 분리하거나 전용 주먹 손 이미지로 가림 관계를 고정한다. contact 팔로 교체할 때도 knuckle 좌표를 제공하고 날이 손에서 떨어지지 않게 한다.

### 활·시위·화살 및 두 손 파지

현재 bow 애니메이션은 포즈 뼈대만 있고 실제 활/시위/화살은 없다. 새 bow 이미지에는 `grip`, `tip_upper`, `tip_lower`, `nock` 앵커를 둔다. idle 시위는 양 끝을 연결한 직선, draw 시위는 위 끝→당긴 nock→아래 끝으로 이뤄진 두 선분이다. 활 자체는 기존 near hand grip을 따라간다. 시위와 화살은 별도 렌더 노드/간단한 선 렌더가 필요하다. 화살 꼬리는 nock에, far 손은 draw_hand 앵커에 맞추고 release 550ms에 화살 표시/발사를 전환한다. 줄을 활 그림에 고정한 채 당기는 시늉만 하지 않는다.

양손 창·양손검·큰 도끼는 주 손 grip을 기준으로 무기를 배치한 후 무기 `offhand`의 월드 좌표에 보조 손을 맞춘다. 현재 offhand 메타데이터는 이를 자동으로 수행하지 않는다. 짧은 한 덩어리 팔에 무리한 길이 변경을 적용하지 않고, 동작별 보조 팔 교체 이미지와 무기 각도 키를 함께 설계한다. 제작 시 오차가 남으면 제한된 보조 손 앵커 해석을 추가한다. 좌우 반전 전 동일 좌표계에서 계산하고, 공격·걷기 키 사이의 보간 구간도 점검한다. 라인업에는 기사 창 한 가지를 보여주며 양손검은 추후 무기 변형으로 제작한다.

## 피부 4종 · 직업별 염색 4종

의상 전체 또는 얼굴 전체에 일괄 multiply를 쓰지 않는다. **부품별 의미 마스크를 이용한 빌드 시 재색칠**을 채택한다. 채널은 `skin_base`, `skin_shadow`, `cloth_main`, `cloth_main_shadow`, `cloth_accent`, `cloth_accent_shadow`이며 필요할 때만 가죽 채널을 추가한다. 선·눈·금속·크림 안감·무기날은 마스크에서 제외한다. 마스크는 원본과 같은 캔버스/pivot을 쓰며 안티앨리어싱 경계의 coverage와 원본 alpha를 보존한다.

얼굴·귀·목·팔·무릎·손에 같은 skin token을 적용한다. 장갑으로 가려진 부분은 피부 마스크가 없다. 성별 얼굴 모두 눈/눈썹/입은 재색칠 대상에서 제외한다. 최초 승인 Novice/Swordsman의 기본 외형은 기존 원본을 그대로 사용할 수 있도록 `original` 재질을 남긴다. 새 4색 변형만 마스크로 굽는다. 실제 배포는 공통 부품 중복 제거 후 재질 키로 캐시하며 13×8×2×4×4의 완성 캐릭터를 통째로 굽지 않는다.

## 머리 8종과 얼굴 2종

`hair_faces.png`의 열은 01 기본 단발, 02 짧은 삐침, 03 옆가르마, 04 둥근 단발, 05 높은 묶음, 06 낮은 묶음, 07 작은 올림, 08 한쪽 땋음이다. 윗줄 여성형·아랫줄 남성형으로 같은 머리 형태를 두 얼굴에 공유한다. 얼굴 외곽/귀/턱/pivot은 같고 눈·눈썹 형태만 소폭 바꾼다. 01은 승인된 Novice 앞머리·뒷머리를 기준으로 삼는다.

8종 모두 제작 원본은 크림 기본색 `#FFF4D8` / 그림자 `#E4CBA5`의 front/back 한 세트다. 묶음·올림·땋음도 기본은 back 이미지에 포함하고 움직임이 필요해질 때에만 tail 노드를 추가한다. 이마/귀를 기준으로 연결선을 감추며 모자 대응 변형에도 pivot을 유지한다.

총 16개 중 13개는 크림색, 남성형 02·03·04만 각각 갈색 `#9F6339`, 파랑 `#5986D0`, 검정 `#59535D` tint 예시다. 기존 엔진 계약대로 RGB multiply 후 원본 alpha 복원이며 머리 이외에는 적용하지 않는다. 검정은 순수 `#000000`을 쓰지 않아 그림자 면을 남긴다. 컨셉 시트의 세 사례는 외관 검토용 생성 이미지이며 실제 multiply 계산 결과를 검증한 렌더라고 주장하지 않는다. 승인 후 원본을 정규화하고 같은 세 색을 실제 조립기로 다시 출력해 확인한다.

## 제작 순서와 배치

1. 이번 두 시트에서 의상·머리 형태를 먼저 승인받는다. 승인 전에는 부품을 제작하지 않는다. 이후 아래 단계는 별도 제작 의뢰 범위다.
2. 승인된 Novice를 크기/선/얼굴의 골든 샘플로 고정한다. 공통 얼굴 2종과 피부 마스크, 크림 머리 8종을 한 배치에서 제작한다. 매 배치에 기존 샘플을 동일 배율로 붙여 비교하며 새 생성물을 다음 배치의 유일한 기준으로 삼지 않는다.
3. 계약 확장용 최소 시험: Novice 기본 렌더 무변경, 로브 하부 한 벌, 모자 가림, 방패, 활 시위, 카타르, 두 손 grip을 각각 검증한다. 시험용 부품도 실제 제작 의뢰 이후 만든다.
4. 기존 검사 → 기사: 승인된 판금/파랑/빨강을 직접 상속한다. 장갑·갑옷 팔, 창·방패·양손검 파지를 함께 확정한다.
5. 마법사 → 위저드, 성직자 → 프리스트: 로브 네 벌을 같은 배치로 제작해 하체 길이·밑단·소매 접속 규격을 통일한다. 보라/남색과 흰색 계열을 각 쌍으로 비교한다.
6. 궁수 → 헌터: 활·당기는 팔·화살통을 공동 제작하고 80px에서 초록 농도/활 크기/몸통 가드가 구별되는지 확인한다.
7. 도둑 → 어새신: 짧은/긴 스카프, 단검/주먹 카타르를 한 배치에서 비교한다.
8. 상인 → 블랙스미스: 짧은/긴 앞치마와 맨손/장갑, 작은/큰 도끼를 함께 만든다.
9. 모든 클래스의 기본색을 확정한 뒤 마스크 기반 피부 4종·염색 4종을 일괄 굽는다. 색상별 재생성으로 선과 디테일이 달라지지 않게 한다. 마지막에 각 계보를 위아래로 놓은 동일 배율 조립 시트를 다시 출력한다.

## 후속 제작의 수락 기준

- 확대 조립뿐 아니라 실제 기준 높이 80px에서 얼굴·무기·직업의 큰 색면과 실루엣을 확인한다. 모자 포함 bounding box에 맞춰 직업별 축소하지 않는다.
- 모든 부품의 크기/pivot/앵커를 숫자로 명시한다. 기존 변환/접촉 grip 검증을 유지하고 새 방패·시위·보조 손 앵커를 검사한다. 시위·손·무기 접속 오차는 기준 캔버스에서 1px 이하를 목표로 한다.
- idle/walk/melee/bow/cast/sit/hurt/dead와 양방향을 확인한다. 접촉 키뿐 아니라 중간 시간도 확인하여 팔 교체 경계, 로브 틈, 방패 겹침, 손 파지 이탈을 잡는다.
- 피부 4종 모두 손·귀·목·무릎이 일치하고 머리 tint가 얼굴에 번지지 않아야 한다. 모자×8머리, 얼굴 2종 교환, 길어진 장비의 화면 잘림을 확인한다.
- 컨셉 이미지를 실제 조립 검증 결과로 혼동하지 않는다. 이번 두 PNG는 디자인 승인용이며 기존 부품과 픽셀 단위 일치·80px 런타임 성능 검증은 후속 제작 단계의 책임이다.
