# Novice 조립 에셋 제작 계획

## 제작 방식

고정 좌표의 짧은 컷아웃 리그 + 접촉 프레임용 팔 교체를 사용한다. 승인 이미지의 큰 머리, 목이 가려지는 턱선, 짧은 하체를 기준으로 먼저 조립 비율을 확정하고, 그 비율에 맞춰 부품 PNG를 정규화한다. 개별 이미지 크기로 관절을 추정하지 않는다.

모든 동작·장비 조합을 통째로 다시 그리는 방식은 13개 의상 × 8개 머리 × 10개 색 × 얼굴·장비 조합에서 관리 비용과 프레임 간 얼굴 변동이 커진다. 반대로 긴 팔다리를 회전하는 기존 방식은 승인 목업과 다른 체형을 만든다. 이번에는 짧은 팔/다리, 몸통 아래 감춰지는 관절, 공격용 수평 팔을 조합한다.

범위는 Novice 여자 1종, Swordsman 의상, 흰 머리 1종, 얼굴 1종, 새싹·별 머리핀, 단검·검이다. 나머지 직업/머리/얼굴/무기는 같은 계약으로 확장하며, 이 납품에 전체 종류가 그려졌다는 뜻은 아니다.

## 제작·검증 순서

1. 승인 디자인을 참조한 투명 부품 원화 생성. 원화와 프롬프트 보존.
2. 부품을 분리하고 실제 최종 픽셀 크기로 정규화. 바지 중복 제거, 어깨/허벅지 연결부 은폐.
3. 픽셀 좌표의 pivot/anchor, 장비 슬롯, 명시적 레이어 순서 작성.
4. manifest만 읽는 조립기로 idle/walk/attack contact/의상 교환/머리장식 조합을 출력.
5. 80px 실제 크기와 확대 조립 결과를 확인하고 좌표·크기 수정.

상세 계약과 검증 결과는 실제 조립 후 아래에 기록한다.

## 최종 납품과 실행

- `parts/`: 실제 알파 채널을 가진 PNG 16개. 마젠타 키잉 불필요.
- `manifest.json`: 부품, 부모 관계, 소켓, 두 의상 묶음, 장비 슬롯, 색상 10개, 8개 동작의 키프레임.
- `preview_assembled.png`: idle / walk / 공격 접촉 / Swordsman+검 / 새싹+머리핀. 확대와 80px 기준 행.
- `preview_comparison.png`: 승인 목업의 Novice 부분과 같은 높이로 맞춘 조립 결과.
- `preview_states.png`: 나머지 동작을 포함한 검수용 포즈.
- `preview.html`, `renderer.mjs`: Canvas 2D 실시간 조립 예제. 의상·무기·색·장식 변경, 좌우 반전, 시간 스크럽.
- `build.py`, `verify.py`, `raster.swift`: 재현 가능한 추출·조립·검증 도구.
- `source/atlas.png`, `source/PROMPTS.md`: built-in imagegen 원화와 사용 프롬프트.
- `verification/report.json`: 크기·RGBA·관절·접촉 방향·Canvas 구현과 독립 조립기의 수치 비교 결과.

기존 Vite 서버가 켜져 있으면 `http://localhost:4200/docs/art/rig-codex/preview.html`에서 확인한다. 파일을 직접 더블클릭하는 방식은 JSON fetch 때문에 지원하지 않는다. 별도 서버는 저장소 루트에서 `python3 -m http.server 8240` 실행 후 같은 경로를 연다.

재생성은 저장소 루트에서 다음 순서로 실행한다. macOS의 Swift/AppKit과 Python 표준 라이브러리, Node만 사용한다. Pillow나 외부 패키지는 필요 없다.

```sh
swiftc -module-cache-path docs/art/rig-codex/.swift-cache docs/art/rig-codex/raster.swift -o docs/art/rig-codex/.raster
python3 docs/art/rig-codex/build.py
python3 docs/art/rig-codex/verify.py
```

## 에셋 계약

### 좌표와 스케일

조립 공간은 **384×320px**, 접지 원점은 **(148,286)**. x는 오른쪽, y는 아래쪽, 각도는 시계방향 도 단위다. 장비 없는 정지 캐릭터의 기준 높이는 약 **257px**이며, 80 CSS px 렌더링 배율은 `80 / 257`이다. 장식과 무기는 이 기준 높이에서 제외한다. 기기 DPR은 이 배율 밖에서 한 번 적용한다.

머리는 `head.scale=[1.18,1.18]`로 검수 후 보정했다. PNG 자체를 프레임마다 임의로 재스케일하지 않는다. `size`는 PNG의 실제 픽셀 크기, `pivot`와 `anchors`는 해당 PNG의 좌상단을 (0,0)으로 하는 픽셀 좌표다. 모든 부품 `restAngle=0`은 PNG의 그려진 방향 그대로를 뜻한다. 수직 팔과 수평 팔의 방향 차이는 이미 원화에 구워져 있으므로 별도 90도 보정이 필요 없다.

`parts`의 파일명은 소문자 snake_case. 예: `novice_arm_contact.png`, `swordsman_torso.png`. `nodes`는 `body`, `head` 같은 빈 부모 노드와 실제 그리기 노드를 함께 가진다. 루트 `body.offset`만 캔버스 절대 좌표이며 나머지 `offset`은 부모 pivot에 대한 상대 좌표다.

부모의 특정 anchor에 붙을 경우 이동량은 다음과 같다.

```
localOffset = parentPart.anchors[anchor] - parentPart.pivot + node.offset
nodeMatrix = parentMatrix × translate(localOffset) × rotate(angle) × scale(scale)
drawMatrix = nodeMatrix × translate(-part.pivot)
```

anchor가 없으면 부모 pivot에 `offset`만 더한다. 자식의 pivot이 부모 anchor에 정확히 붙는다. weapon의 `worldAngle`은 캔버스 기준 절대 각도이며, 계산된 손 위치와 배율은 유지하고 회전만 덮어쓴다. **접촉 시 worldAngle=0**으로 칼끝을 오른쪽에 둔다. 왼쪽 방향은 모든 조립을 완료한 뒤 접지 원점에서 한 번만 미러링한다.

### 레이어와 장착

기본 z: 뒷머리 10, 뒷다리 30, 앞다리 35, 몸통 40, 얼굴 70, 앞머리 80, 무기 85, 앞팔/주먹 90, 상단 장식 100, 중단 장식 110. 먼 팔은 node z=45로 몸통의 열린 소매 가장자리를 덮는다. 활 당김에서는 먼 손이 얼굴 앞에 오도록 z=95로 교체한다. z 오름차순, 같은 z는 node 이름 순서다.

의상 교환은 `outfits`에서 torso / arm_near / arm_far / arm_contact를 한꺼번에 바꾼다. 두 납품 의상은 기본 부츠를 공유한다. 향후 의상 전용 다리가 필요하면 노드의 part를 leg 슬롯으로 바꾸고 의상 묶음에 포함한다. 원화의 허벅지 상단에 남았던 바지 형태는 추출 영역에서 제외했다. 몸통이 허벅지 상단을 덮으며 바지가 중복되지 않는다.

머리는 앞머리와 뒷머리를 함께 교환한다. `hairStyles`의 각 항목이 이 쌍을 지정한다. `renderer.mjs`의 `look.hairStyle`로 선택한다. 추가 7종은 동일한 head pivot, 얼굴 노출 범위, top/mid 소켓을 준수해야 한다. 10개 색은 RGB multiply 후 원본 alpha로 마스킹한다. 피부·눈·의상에는 tint를 적용하지 않는다. 현재 흰 원화가 약간 크림색이어서 파랑 등은 순수 RGB 값보다 따뜻하고 어둡게 나온다.

얼굴은 `look.face`로 전체 face PNG를 교환한다. 두 번째 얼굴은 같은 크기·pivot으로 제작한다. 현재 실제 납품 얼굴은 1종이다. top은 앞머리의 `top`, mid는 앞머리의 `mid`, low는 얼굴의 `low` 소켓을 사용한다. 새싹과 머리핀은 서로 다른 슬롯이므로 동시 장착된다. 하단 슬롯의 장식 원화는 이번 범위에 없다. 베레모처럼 머리를 가리는 큰 장식은 별도 앞/뒤 파트와 hair-hide 규칙을 추가해야 한다.

무기는 앞팔의 `grip`에 붙는다. 무기 pivot은 손잡이 중심, `tip`은 칼끝이다. 손이 무기보다 나중에 그려져 손잡이를 덮는다. 팔 교체 시 해당 PNG의 grip을 사용하므로 수평 팔로 바뀌어도 무기가 분리되지 않는다. 앞으로 추가할 8종도 grip/tip 축으로 제작하고, 양손 무기는 offhand 소켓과 전용 손 포즈를 추가한다. 무기별 실제 궤적과 크기는 별도 검수해야 한다.

### 애니메이션 계약

시간은 ms. 숫자·좌표·scale은 키 사이에서 선형 보간한다. 키에서 생략된 필드는 **이전 키 유지가 아니라 rest node 값**으로 복귀한다. part 슬롯, visible, z 같은 이산 값은 키 시점에 전환한다. 루프 동작은 duration으로 나머지 연산, 비루프 동작은 마지막 키에서 정지한다. 현재 원화 16개로 구현한 방식은 다음과 같다.

| 동작 | 구현 | 비고 |
|---|---|---|
| idle | 1200ms, 몸통 2px 상하 이동 + 0.8% 세로 변화 | 머리·장비가 부모를 따라감 |
| walk | 640ms, 다리 교차 회전·작은 hip 이동·팔 역상 | 강한 달리기보다 짧은 보행 |
| melee | 500ms, 준비→220ms 수평 팔 교환→회수 | contact 이벤트, 검·단검 끝이 전방 |
| bow | 850ms, 앞팔 고정·먼 손을 볼 쪽으로 당김→550ms 놓음 | **자세 설계만 납품**. 활·화살·시위 원화 없음 |
| cast | 900ms, 앞손 상승·몸통 들림, 420ms 이벤트 | 무기 숨김, 마법 VFX 별도 |
| sit | 500ms, 몸통 하강·다리 전방 회전 | 부츠의 사선 원근은 단순화 |
| hurt | 400ms, 뒤로 이동·몸통/머리 기울임 | 전용 피격 표정 없음 |
| dead | 550ms, 전신 -90도 회전 후 접지 위치 조정 | 누운 상태, 전용 감은 눈 없음 |

## 스타일 및 조립 검증

원화는 built-in imagegen으로 생성하고, 그 이후 분리·크기 정규화·pivot 지정·조립은 스크립트로 수행했다. 생성된 완성 캐릭터를 미리보기로 대신 붙이지 않았다. 모든 납품 미리보기의 캐릭터는 실제 manifest와 부품으로 조립했다. 승인 목업 crop은 `preview_comparison.png`의 왼쪽 비교용으로만 사용한다.

수정 기록:

1. 긴 다리·이중 바지 문제를 피하도록 원화의 바지 상단을 추출에서 제외하고 다리 높이를 58px로 고정.
2. 초기 조립의 먼 어깨 구멍 노출을 발견하여 먼 팔의 위치와 z를 조정.
3. 반대 보행 스텝의 과도한 발 교차를 줄이도록 각도와 hip 위치 수정.
4. 승인 목업과 동일 높이 비교에서 머리가 아직 작아 보여 head 그룹을 18% 확대. 보정 전 비교는 `verification/comparison_before_head_calibration.png`에 보존.
5. 확대된 머리의 사망 포즈가 캔버스를 넘지 않도록 누운 위치 재배치. 앉은 자세도 접지 높이에 맞춤.

검증 결과:

- 16개 PNG의 파일 크기/manifest 일치, RGBA 타입, pivot/anchor 범위 확인.
- 2개 의상 × 2개 무기 × 모든 동작 키, 장식 동시 장착을 포함한 **116조합**의 부모 연결·유한 행렬·384×320 캔버스 내 부품 사각형 검사 통과.
- 접촉 키에서 손 grip과 무기 pivot 거리 **0px**, 검·단검 tip 방향 **0도** 확인.
- 실제 Canvas용 `renderer.mjs`와 독립 Python 조립기의 116조합 행렬 차이 **1e-8 미만**.
- 확대 PNG와 80px 행을 육안 확인. 큰 머리, 짧은 다리, 목을 가리는 머리/턱, 갈색 외곽선, 한 벌의 튜닉, 무기와 주먹의 겹침이 이전 실패 조립보다 승인 디자인에 가깝다.
- 브라우저 제어 연결을 사용할 수 없어 HTML의 실제 재생 화면은 확인하지 못했다. JS 문법 검사와 조립 행렬의 동등성 검증은 완료했다. 애니메이션의 모든 중간 프레임에 대한 시각적 검수나 기기별 FPS 측정은 수행하지 않았다.

### 남은 차이 — 완전 동일 판정 아님

승인 장면의 뛰는 동작은 원근 단축과 팔꿈치·무릎 굽힘이 더 풍부하다. 이번 보행은 짧은 컷아웃 회전이라 더 차분하고 정면에 가깝다. 머리 실루엣과 크림색/갈색/파랑의 큰 색 영역은 맞췄지만, 목업의 종이 질감·소매의 흰 스티치·미세한 얼굴 비대칭은 동일하지 않다. 새 원화의 선은 더 깨끗하고 색면은 조금 더 매끈하다. 수평 팔 교체 시 실루엣 변화가 있어 아주 느린 재생에서는 전환이 보일 수 있다.

따라서 **런타임 교환 가능한 검증된 기본 세트**로 납품한다. 승인 목업과 픽셀 수준으로 동일하거나 전체 13직업/8머리/2얼굴/10무기와 모든 전용 액션 원화가 완성되었다고 주장하지 않는다. 다음 원화 확장도 이 manifest로 80px 조립 검수를 통과시킨 후 추가해야 한다.
