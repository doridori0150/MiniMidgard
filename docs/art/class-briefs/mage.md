# 직업: 마법사 (mage)

- 공통 요청서: `docs/art/CLASS_PIXEL_BRIEF.md`를 따릅니다.
- **캐릭터 id:** `mage_female_p2`. 성별은 여성입니다. 외형은 아스트라가 새로 디자인합니다.
- **무기:** 지팡이. 게임 무기 종류 `staff`, 무기 레이어 이름 `staff`.
- **동작:** 대기, 걷기, 공격, 시전(cast), 피격, 쓰러짐, 앉기. 마법사는 사냥 대부분을 시전으로 하므로 **cast는 반드시 넣습니다.**
- **라그나로크 레퍼런스:** `job=2&gender=female&weapon=10`, 남동 방향 시트를 첨부합니다.
  - **w-attack1 (지팡이 공격, 9장):** 지팡이를 머리 위로 높이 들었다가 몸 앞으로 내려칩니다. 내려친 뒤 몸을 숙인 자세로 오래 멈춥니다.
  - **w-attack3 / cast (6장):** 두 손을 가슴 앞에 모았다가 앞으로 뻗어 내밉니다.
  - **standby (6장):** 지팡이를 비스듬히 내려 든 전투 대기입니다.
  - **hurt (3장):** 뒤로 젖혀집니다.
  - **dead (1장):** 엎드려 쓰러집니다.
- **시전 루프:** 게임에서는 시전 시간 동안 cast를 반복합니다. 두 손을 모으는 준비 장면 → 반복되는 유지 장면 순서로 만들고, `loop`가 자연스럽게 이어지게 합니다.
