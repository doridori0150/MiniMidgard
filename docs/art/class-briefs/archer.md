# 직업: 궁수 (archer)

- 공통 요청서: `docs/art/CLASS_PIXEL_BRIEF.md`를 따릅니다.
- **캐릭터:** `archer_male_p2`. 남성이며, 외형은 아스트라가 새로 디자인합니다. 쿠키·기사·마법사와 같은 2등신입니다. 남성 얼굴은 눈썹이 굵고 곧고, 속눈썹 꺾임이 없습니다.
- **무기:** 활. 게임 무기 종류는 `bow`, 무기 레이어 이름도 `bow`입니다.
  - 활은 목표(화면 오른쪽) 쪽으로 뻗은 팔이 쥡니다.
  - 다른 손은 시위를 당깁니다.
  - 활을 쥔 손은 모든 프레임에서 같습니다.
- **동작:** 대기, 걷기, 공격(활 쏘기), 피격, 쓰러짐, 앉기. 시전(cast)은 넣지 않습니다.
- **화살:** 게임이 따로 날립니다. 시위를 놓는 장에서 화살이 활을 떠나게 그리고, 날아가는 화살은 그리지 않습니다.
- **라그나로크 레퍼런스:** `job=3&gender=male&weapon=11`, 남동 방향 시트를 첨부합니다.
  - **w-attack1 (활 공격, 9장):**
    1. 활을 들어 올립니다.
    2. 시위를 귀 옆까지 당기며 몸을 엽니다.
    3. 놓습니다.
    4. 뒤 장들에서는 쏜 자세로 시위가 흔들리는 걸 오래 유지합니다.
  - **idle (8장):** 몸을 살짝 흔드는 숨쉬기입니다.
  - **standby (6장):** 활을 아래로 든 전투 대기입니다.
  - **hurt (3장):** 뒤로 젖혀집니다.
  - **dead (1장):** 뒤로 누워 쓰러집니다.
- **타이밍:** 게임에서 화살은 공격 시작 후 짧은 공격 시간의 약 60% 지점에 나갑니다. 시위를 놓는 장에 `hitFrame`을 둡니다.
