# 직업: 초보자 (novice)

- 공통 요청서: `docs/art/CLASS_PIXEL_BRIEF.md`를 따릅니다.
- **캐릭터:** `novice_female_p2`, 여성. 외형은 아스트라가 새로 디자인합니다.
  - 모든 플레이어가 처음 보는 캐릭터입니다. 수수한 여행자 차림으로, 앞으로 어떤 직업이든 될 수 있을 것 같은 인상이면 됩니다.
- **무기:** 단검. 게임 무기 종류와 무기 레이어 이름 모두 `dagger`입니다. 도둑의 `dagger` 레이어와 이름은 같지만 프레임은 캐릭터별로 따로 둡니다(`weapons.dagger.frames.novice_female_p2`).
- **머리:** 이름 앞에 직업을 붙입니다(`novice_…_p2`).
- **동작:** 대기, 걷기, 공격, 피격, 쓰러짐, 앉기. 시전은 넣지 않습니다.
- **라그나로크 레퍼런스:** `job=0&gender=female&weapon=1`, 남동 방향 시트를 첨부합니다.
  - **w-attack2 (단검, 8장):** 단검을 몸 앞에 들고 있다가, 몸을 낮추며 앞으로 내디뎌 찌르고, 그대로 멈춥니다.
  - **attack(bare) (5장):** 주먹을 뒤로 뺐다가 몸을 숙이며 앞으로 뻗습니다.
  - **idle (3장):** 가만히 서 있습니다.
  - **sit (3장):** 무릎을 꿇고 앉습니다.
  - **hurt (3장):** 뒤로 젖혀집니다.
  - **dead (1장):** 엎드려 쓰러집니다.
- **공격 느낌:** 서툴지만 씩씩한 초보 모험가답게, 짧고 가벼운 단검 찌르기로 합니다.
