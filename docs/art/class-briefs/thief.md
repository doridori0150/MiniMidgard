# 직업: 도둑 (thief)

- 공통 요청서: `docs/art/CLASS_PIXEL_BRIEF.md`를 따릅니다.
- **캐릭터:** `thief_male_p2`. 남성이며, 외형은 아스트라가 새로 디자인합니다. 날렵하고 가벼운 옷차림입니다. 남성 얼굴은 눈썹이 굵고 곧습니다.
- **무기:** 단검. 게임 무기 종류는 `dagger`, 무기 레이어 이름도 `dagger`입니다. 2차 어새신이 쓰는 카타르도 이 단검 그림으로 보입니다.
- **동작:** 대기, 걷기, 공격, 피격, 쓰러짐, 앉기. 시전(cast)은 넣지 않습니다.
- **라그나로크 레퍼런스:** `job=6&gender=male&weapon=1`, 남동 방향 시트를 첨부합니다.
  - **w-attack1 (단검, 9장):**
    1. 단검을 몸 옆에 낮게 듭니다.
    2. 팔을 뒤로 쭉 뻗어 단검을 뒤로 뺍니다.
    3. 몸을 낮추며 큰 수평 잔상으로 앞을 가로 베어 냅니다.
    4. 낮게 앞으로 내디딘 채 단검을 앞으로 뻗고 멈춥니다.
  - **idle (3장):** 가볍게 서 있는 대기입니다.
  - **standby (6장):** 단검을 아래로 비스듬히 든 낮은 자세입니다.
  - **hurt (3장):** 뒤로 젖혀집니다.
  - **dead (1장):** 엎드려 쓰러집니다.
- **느낌:** 빠르고 날렵하게 만듭니다. 감기는 짧게, 가로 베기와 낮은 자세는 분명하게 보이게 합니다.
