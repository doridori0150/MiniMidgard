# 직업: 복사 (acolyte)

- 공통 요청서: `docs/art/CLASS_PIXEL_BRIEF.md`를 따릅니다.
- **캐릭터:** `acolyte_female_p2`. 여성이며, 외형은 아스트라가 새로 디자인합니다. 성직자다운 옷차림입니다.
- **무기:** 철퇴. 게임 무기 종류는 `mace`, 무기 레이어 이름도 `mace`입니다.
- **동작:** 대기, 걷기, 공격, **시전(cast)**, 피격, 쓰러짐, 앉기. 복사는 힐·축복을 계속 시전하므로 **시전은 반드시 넣습니다.** 마법사처럼 `cast_start`(한 번만 재생) + `cast`(반복)로 나누어도 됩니다. 게임이 그 구조를 읽습니다.
- **라그나로크 레퍼런스:** `job=4&gender=female&weapon=8`, 남동 방향 시트를 첨부합니다.
  - **w-attack1 (철퇴, 9장):**
    1. 철퇴를 머리 위 뒤로 크게 치켜듭니다.
    2. 갈색 잔상을 남기며 앞 아래로 내려칩니다.
    3. 내려친 자세에서 몸을 숙이고 철퇴를 앞으로 내민 채 오래 멈춥니다.
  - **w-attack3 / cast (6장):** 두 손을 가슴 앞에 모아 기도하듯 쥡니다.
  - **idle (3장):** 두 손을 앞에 모은 얌전한 대기입니다.
  - **standby (6장):** 철퇴를 어깨에 기대 듭니다.
  - **hurt (3장):** 뒤로 젖혀집니다.
  - **dead (1장):** 쓰러집니다.
- **시전 동작:** 두 손을 모아 기도하는 자세를 기본으로 합니다. 철퇴는 손에 쥔 채 두거나 몸 옆으로 내립니다. 쥐는 손은 바꾸지 않습니다.
