# 직업: 상인 (merchant)

- 공통 요청서: `docs/art/CLASS_PIXEL_BRIEF.md`를 따릅니다.
- **캐릭터:** `merchant_female_p2`, 여성. 외형은 아스트라가 새로 디자인합니다. 씩씩한 장사꾼 차림이고 앞치마나 가방이 어울립니다.
- **무기:** 도끼, 게임 무기 종류 `axe`. 무기 레이어 이름도 `axe`입니다.
- **머리 이름:** 직업 접두어를 붙입니다(예: `merchant_…_p2`).
- **동작:** 대기, 걷기, 공격, 피격, 쓰러짐, 앉기. 시전은 넣지 않습니다.
- **라그나로크 레퍼런스:** `job=5&gender=female&weapon=6`, 남동 방향 시트를 첨부합니다.
  - **w-attack1 (도끼, 9장):** 도끼를 머리 위 뒤로 높이 치켜듭니다. 큰 부채꼴 잔상과 함께 앞 아래로 무겁게 내려찍습니다. 무릎을 굽혀 몸을 낮추고, 도끼날이 땅에 닿은 채 오래 멈춥니다.
  - **idle (3장):** 팔짱을 낀 듯 당당하게 서 있습니다.
  - **standby (6장):** 도끼를 몸 앞에 비스듬히 든 자세입니다.
  - **hurt (3장):** 뒤로 젖혀집니다.
  - **dead (1장):** 쓰러집니다.
- **공격 느낌:** 기사보다 무겁게. 치켜드는 준비 동작을 조금 길게, 내려찍은 뒤 멈추는 시간도 깁니다.
