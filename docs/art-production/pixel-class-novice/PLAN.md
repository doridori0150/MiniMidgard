# 노비스 제작 전 계획

- 새 여성 여행자: 짧은 낮은 묶음머리, 리넨 셔츠, 수수한 올리브 조끼, 갈색 반바지와 부츠, 작은 황토색 목수건. 판금·긴 망토·장식 왕관 없음.
- Knight r15 / 쿠키 r12의 픽셀 밀도와 2등신을 맞춤. 대기 키 48px, 머리 약24px, 128×120, 발 기준 (64,112), 오른쪽 3/4.
- `novice_female_p2`, 머리 `novice_short_tail_p2`, 무기 `dagger`, 같은 가까운 손 유지. 머리 네 키색 분리. imagegen 개별 원화 제작 후 r15와 같이 정규화·레이어 분리.
- 첨부 RO 노비스는 동작만 관찰. 원본 픽셀·이미지는 저장하거나 사용하지 않음. 오래된 노비스 외형 자료는 사용하지 않음.

|동작|장수|시간(ms)|계획|
|---|---:|---|---|
|idle|3|420,300,120|편안한 대기, 미세한 호흡, 원위치|
|walk|6|90×6|앞발 접지, 통과, 반대 접지, 체중 교대와 팔의 작은 역운동|
|attack|6|100,120,60,100,80,60|몸 앞 준비, 당김/하강, 짧게 전진 찌르기(hitFrame=2), 낮은 자세 유지, 회수, idle 복귀|
|hurt|2|90,150|뒤로 젖혀짐, 긴장 완화|
|dead|3|100,140,1000|무릎 꺾임, 앞으로 넘어감, 엎드려 정지|
|sit|1|1000|무릎 꿇고 쉬기|

공격 총520ms, 타격220–280ms로 중앙260ms를 포함. 최종 장은 idle_0 레이어 그대로 재사용. 각 원화는 직전 채택 이미지를 확인한 다음 한 장씩 생성하고 검수 기록을 남김. 동일 얼굴·머리 크기·복장·단검 손·접지·가동 범위를 확인. 어긋난 장은 수정 후 다음으로 진행.

최종: manifest / body / hair / weapons / grips, 합성본, 여섯 동작 1×·4× GIF, 전체 시트, 쿠키·기사·노비스 비교 1×·4×, 검증 기록과 짧은 NOTES. 쓰기는 이 폴더에만, 게임 코드·다른 자산·커밋·푸시 변경 없음.

대기 검토 후 눈감은 장을 120ms로 줄이고 나머지를 420/300ms로 조정했다. 단검은 모든 장에서 손잡이-끝 10px로 정규화한다.
