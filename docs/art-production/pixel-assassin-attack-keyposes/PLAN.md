# 제작 계획

원문 및 사용자 말·그림 규칙 세 가지는 REQUEST.md에 그대로 보존했다.

1. 기사에서는 픽셀 밀도·외곽선·눈·2등신·명암 단계만, 승인 어새신에서는 외형과 색을 참조한다. RO 시트는 외부 임시 경로에서 자세·순서·리듬만 확인하며 복사하지 않는다.
2. 준비 → 정점 → 접촉 → 회수를 한 장씩 생성한다. 생성 입력은 매번 동일한 승인 어새신과 기사 및 동작 참조이며, 직전 생성물을 다음 장의 이미지 참조로 쓰지 않는다.
3. 각 장을 본 뒤 승인 외형 유지와 이전 자세의 연결을 검토하고 다음 장으로 진행한다. 정점은 가장 낮고 압축된 자세, 접촉은 가장 전방의 칼끝, 회수는 같은 가까운 팔을 유지한다.
4. 각 장은 투명 128×120, 발 기준 (64,112), 머리 폭 30px 이하. 웅크림은 축소가 아닌 관절 변화로 표현한다. 생성 원본을 게임 픽셀 규격으로 정규화하고 몸·뒷머리·앞머리·카타르·그립을 분리한다.
5. 게임 순서(뒷머리 → 뒤 무기(해당 시) → 몸 → 앞머리 → 앞 무기(해당 시) → 그립)로 합성한다. 접촉의 짧은 잔상은 카타르 레이어에만 포함한다.
6. 512×120 시트·최근접 4배 확대·요청된 비교 시트·좌표 메타데이터·짧은 검수 기록을 납품한다. 승인 이미지는 원래 경로에서 읽어 비교 시트에 합성하며 참조 단독 파일을 복사하지 않는다.

사이 장·애니메이션·게임 적용은 이번 범위에 없다. 승인 여부는 사용자 공방 검토에 남긴다.
