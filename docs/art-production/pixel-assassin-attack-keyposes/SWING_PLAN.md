# 사이 장 제작 계획

사용자 말과 그림 규칙 세 가지는 SWING_REQUEST.md에 원문 그대로 보존한다.

1. 승인 어새신의 얼굴·마스크·머리 4색·자주색 조끼·남색 두 갈래 천·황동 장식·가까운 손 카타르를 확인한다. 기사는 픽셀 밀도와 외곽선·명암만, 외부 RO 시트 w-attack1 다섯째 장은 허리 높이의 넓은 가로 잔상 배치만 참조한다. 참고 이미지는 복사하지 않는다.
2. 정점 → 휘두름 → 접촉을 먼저 설계한다. 머리는 정점과 접촉 사이 높이, 몸통은 표적 쪽으로 돌아가고 가까운 팔은 허리를 가로지른다. 한 장만 생성하고 정점 및 접촉과 비교한다.
3. 뒷발의 108–111행 최소 x는 52. 앞발은 정점과 접촉 사이에서 111행에 닿게 한다. assembly의 정점 +6, 접촉 +3 이동도 함께 읽어 실제 고정발 기준의 연결을 확인한다. 이 장은 추가 이동 없이 사용할 좌표로 제작한다.
4. 넓고 옅은 초승달 잔상은 katar 레이어에만 둔다. 몸·머리·그립을 분리하며 원본 승인 포즈는 수정하지 않는다.
5. 128×120, 발 기준 (64,112), 웅크린 키 41–44px, 머리 폭 30px 이하, 이진 알파, 머리 4색, 합성 일치, 최근접 4배, 앵커와 파일 보존을 검증한다. 애니메이션이나 조립표는 변경하지 않는다.
