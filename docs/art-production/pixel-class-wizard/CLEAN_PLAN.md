# 보강 2 — 레이어 정리 계획

동작·크기 레퍼런스: 첨부 RO 여성 위저드 시트는 기존 자세·순서 확인에만 사용한다. 쿠키 r12·기사 r15 비교 시트의 2등신·48px 밀도와 현재 위저드 디자인을 유지한다. 외부 참조 파일은 복사하지 않는다.

1. 매니페스트·원화·그립·등록 좌표의 해시와 수정 전 레이어를 보존한다. 포즈·타이밍·128×120 캔버스·발 (64,112)은 고정한다.
2. 기존 등록 프로그램의 레이어 분리 경계를 고친다. 원화에서 잘못 몸에 배정된 지팡이 픽셀만 무기로 옮긴다. 몸의 손을 보존하고 손가락 오버레이는 그대로 둔다. 지팡이가 있던 몸의 빈 공간은 투명하게 유지한다.
3. 머리의 투명한 내부 구멍과 체크무늬 경계를 네 키 색으로 연결하고 떨어진 한 픽셀을 정리한다. 얼굴·장식·땋은 머리·두상·기존 색조를 보존한다.
4. 원본 포즈를 한 장씩 처리하고 직전 포즈와 나란히 확인한 뒤 다음 장으로 진행한다. 재사용 포즈에도 동일한 수정 결과를 적용하고 83개 재생 프레임의 이전 장 연결을 기록한다.
5. 모든 프레임을 무장·맨손으로 합성한다. verification/clean_armed.png와 clean_bare.png, 전체·동작별 시트·GIF·미리보기를 동기화한다.
6. 변경 범위, 머리 팔레트·연결성·구멍, 무기 분리, 레이어 합성, 타이밍·좌표·그립 불변, 잘림, 28개 스킬을 검증한다. 빌드 캐시를 만들지 않고 이 폴더 안에만 저장한다.
