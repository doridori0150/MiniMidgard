# 헌터 제작 계획

128×120, 발 원점 (64,112), 대기 키 48px, 약 2등신, 오른쪽 3/4. 남성 헌터: 밝은 옆가르마 짧은 머리, 숲색 짧은 어깨 망토, 크림색 목깃, 갈색 가죽 조끼와 장갑·부츠, 황동 버클. 왼손은 화면 오른쪽으로 내밀어 활을 쥐고 오른손은 시위를 당긴다. 매·비행 화살·덫·폭발은 그리지 않는다.

## 순차 원화 계획
- idle: 편안한 준비 → 작은 호흡 → 정착. 3장.
- walk: 왼발 접지 → 하중 → 통과 → 오른발 전진 → 오른발 접지 → 하중 → 통과 → 왼발 전진. 8장.
- attack: 활 올림 → 시위 잡음 → 당김 → 완전 당김 → 놓음(hit) → 반동 → 활 낮춤 → 대기. 8장.
- hurt: 뒤로 젖힘 → 버팀. dead: 무릎 꺾임 → 낮아짐 → 옆으로 눕기. sit: 앉기.
- cast: 활을 세우고 오른손을 가슴에 모은 채 호흡 반복.
- skill_double: 짧은 당김 → 첫 발사(hit, 130ms) → 재장전 당김 → 둘째 발사 → 반동 → 회수.
- skill_sky: 상향 활 준비 → 위로 당김 → 위로 놓음(hit, 130ms) → 유지 → 낮춤 → 대기.
- skill_power: 넓은 보폭·깊은 당김 → 강한 발사(hit, 130ms) → 상체 반동 → 유지 → 회수. arrow_repel / phantasmic 공유. 환영 화살 때문에 실제 화살은 넣지 않음.
- skill_focus: 오른손을 가슴으로 → 눈 감고 집중 → 유지 → 대기. improve_conc. hitFrame 없음.
- skill_falcon: 오른손 들어올림 → 목표로 내뻗어 명령(hit, 130ms) → 유지 → 회수. blitz_beat / falcon_strike.
- skill_scout: 오른손으로 눈 위를 가리고 먼 곳을 살핌 → 유지 → 회수. detect. hitFrame 없음.
- skill_whistle: 오른손을 입으로 → 호각 제스처 → 유지 → 회수. drover_whistle. hitFrame 없음.
- skill_trap: 무릎 낮춤 → 오른손을 발밑에 내려놓음(hit, 130ms) → 접지 유지 → 일어서기 → 대기. 덫 9종 공유.

기본 동작부터 원화를 한 장씩 생성한다. 매 장 직전 원화의 얼굴 크기, 의상, 활 손, 다리 위상을 보고 다음 장을 지시한다. 안정된 준비·유지·복귀 포즈는 모션 사이에 공유할 수 있으나 걷기 8장의 다리 위상은 각각 다르게 제작한다. 정규화는 최근접 표본화, 색 제한 및 레이어 분리에만 사용하며 절차적으로 새 자세를 만들지 않는다.

## 레퍼런스 확인
첨부 RO 남성 헌터: 작은 대기 변화, 8장 보행, 활을 세우고 당긴 뒤 놓는 흐름, 낮은 캐스팅·앉기 참고. 픽셀·비율은 복사하지 않음.
ToS Falconer/Sapper 공식 페이지와 SoC 공식 사이트를 열었다. 실제 모션 확인 범위는 NOTES에 별도 기록한다.
