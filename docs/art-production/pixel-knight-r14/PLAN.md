# R14 — 전진 수평 찌르기

제작 전 계획: r13의 128×120 캔버스, 기준점 (64,112), 대기 키 48px, 머리 약 25px, 크림 단발·청록 판금·금장·같은 가까운 검 손을 유지한다. 다른 동작과 idle은 그대로 보존한다.

Pixel Moon의 Jab와 Mattz Art의 전진·천 지연을 참고한다. lotus_garden의 2타는 첫 타가 기존 내려베기와 겹쳐 채택하지 않는다. 레퍼런스 이미지는 저장하지 않는다.

|프레임|ms|계획|
|---|---:|---|
|0|80|검을 허리에서 앞으로 세우며 무릎을 낮춤. 머리 위로 들지 않음.|
|1|90|뒷다리에 무게를 싣고 팔꿈치를 당김, 검은 수평.|
|2|40|앞발 전진, 몸통이 먼저 이동, 검 팔은 펴지는 중.|
|3|130|최대 전진 찌르기. 앞무릎 굽힘, 뒷발 밀기, 잔상 없음. hitFrame 3.|
|4|70|앞발을 유지하고 팔꿈치부터 검을 회수.|
|5|70|몸을 세우고 발 간격을 좁히며 검을 낮춤.|
|6|80|r13 idle_0 그대로 연결.|

합계 560ms. 각 프레임은 별도 생성한다. 생성 전 직전 프레임을 보고, 생성 후 손·칼 방향·발 접지·머리 크기·허리 천을 비교한다. 합성 후 원본 팔레트와 정수 픽셀로 정규화하고 레이어·GIF·매니페스트·비공격 해시를 검증한다.
