# 여성 마법사 제작 계획

48px, 2등신, 128×120, 발 (64,112), 오른쪽 3/4. 쿠키 r12와 기사 r15만 크기·화풍 기준으로 사용한다. RO 첨부 시트는 포즈·순서·리듬만 관찰하며 복사하거나 저장하지 않는다.

새 디자인: 짧은 물결 단발과 작은 옆 땋음, 네 가지 공용 머리 키색. 자주색 짧은 로브, 크림색 칼라, 금빛 매듭, 짙은 부츠. 과도하게 큰 모자는 쓰지 않는다. 지팡이는 호박색 나무 자루와 작은 민트 수정, 가까운 손으로 잡는다. 시전에서는 지팡이를 같은 손에 둔 채 양손을 가슴 앞으로 모으고 앞으로 내민다.

모든 새 포즈는 imagegen으로 한 장씩 만들고 직전 결과를 확인한 뒤 다음 장의 참조로 사용한다. 처음 만든 대기를 외형 기준으로 계속 함께 전달한다. 완성 픽셀 크기 정규화와 레이어 분리 후 다시 비교한다.

| 동작 | 계획 | 시간(ms) |
|---|---|---|
| idle | 3장, 낮게 비스듬히 든 지팡이와 작은 호흡 | 240,240,240 |
| walk | 6장, 접지→통과→반대 접지→통과, 머리 흔들림 최소화 | 각90 |
| attack | 7장, 들어올림→정점→내려침→접촉→숙인 유지→회수→대기 | 100,120,60,60,160,100,60 |
| cast | 준비 2장, 유지 3장. 가슴 앞 모음→전방으로 뻗음→유지 맥동 | 준비100,120; 유지160,160,160 |
| hurt | 2장, 뒤로 젖힘→충격 완화 | 90,170 |
| dead | 3장, 무릎 붕괴→낮게 기울기→엎드린 정지 | 120,140,1000 |
| sit | 1장, 다리 접고 앉기 | 1000 |

공격 hitFrame=3, 시작 후 280ms(전체660ms의42%)에 접촉. 시전 준비는 cast_start, 게임에서 반복할 cast는 유지 포즈만 담아 루프 경계를 보존한다. 준비→유지 전체 미리보기도 제공한다. 반복 기능에 사용자 정의 필드가 필요하지 않도록 별개 애니메이션으로 분리한다.

검수: 48px 대기 키, 약24px 머리, 같은 얼굴/머리/의상/무기 손, 프레임 간 접지와 지팡이 궤도, 알파 이진화, 네 머리색만 사용, 레이어 재합성, 파일 참조, GIF 크기·시간, 반복 이음, 기존 파일 해시 보존. 작업은 이 폴더에만 저장하며 런타임 변경과 커밋은 하지 않는다.
