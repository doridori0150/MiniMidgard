# 어새신 96px 대기 후보 A·B

내장 **image_gen**으로 같은 `PROMPT.txt`와 원래 참고 3장을 사용해 **독립 생성 2회, 보관 2장, 폐기 0장**. B에는 A를 입력하지 않았다. 사용자 선택 전이며 두 후보 모두 SSOT 미확정이다. 사용자 말과 그림 규칙 세 가지는 `REQUEST.md`·`PLAN.md`에 원문 그대로 보존했다.

- **A — 원본과 차이:** 눈·마스크 경계가 또렷해지고 마스크 아래가 각졌으며, 머리는 화면 왼쪽으로 더 길게 쓸린다. 조끼 어깨·장갑은 두꺼워지고 황동 사선이 강조됐다. 허리 천 두 갈래는 더 넓어졌고 가운데 옷자락이 보이며, 같은 가까운 손의 카타르 가드·날이 분리되어 읽힌다.
- **A — 실루엣:** 48px 원본 ×2와 높이·머리/몸 비율은 맞지만 윤곽은 부분 일치한다. 머리 폭 53px(기준 54px), 어깨는 더 둥글고 발 범위는 x=105–151(기준 104–149)이다. 알파 영역 겹침 비율(IoU) 82.0%는 참고 수치이며 미술적 합격 판정이 아니다.
- **A — 실측:** 키 **96px**, 머리 폭 **53px**, 220–223행 뒷발 최후방 **x=105**, 최하단 **y=223**. 생성 1회·폐기 0장(폐기 사유 없음).

- **B — 원본과 차이:** 눈의 홍채·밝은 점과 V형 마스크가 또렷하며, 머리는 짧은 갈래와 곡선 앞머리로 바뀌었다. 조끼는 가늘고 황동 테두리는 V자로 강조됐다. 허리 천 두 갈래는 뒤로 더 길게 뻗고 가운데 옷자락이 보이며, 같은 가까운 손의 카타르는 날 면이 넓고 뚜렷하다.
- **B — 실루엣:** 48px 원본 ×2와 높이·큰 머리 비율은 맞지만 윤곽은 부분 일치한다. 머리 폭 55px(기준 54px), 어깨·팔은 A보다 가늘고 발 범위는 x=105–150(기준 104–149)이다. 알파 영역 IoU 79.0%.
- **B — 실측:** 키 **96px**, 머리 폭 **55px**, 220–223행 뒷발 최후방 **x=105**, 최하단 **y=223**. 생성 1회·폐기 0장(폐기 사유 없음).

두 후보 모두 실제 256×240 RGBA이며 발 기준은 (128,224)이다. 새 생성 원본에서 한 번의 최근접 샘플링으로 96px에 맞추고, 승인 어새신 팔레트 및 머리 4색으로 정규화했다. 기존 48px 그림의 확대본이 아니다. 외곽선은 기본 1px이며 모서리·겹침에는 어두운 덩어리가 있다. 눈·마스크·조끼 테두리·카타르를 실제 크기와 확대 크기에서 확인했다.

`side_by_side.png` 위에는 **기존 48px ×2 → 해당 96px ×1**, 아래에는 같은 쌍의 **×2**가 있다. 참고 원본은 복사하지 않았으며 비교판에는 요청된 자사 승인 어새신만 기존 경로에서 읽어 합성했다. 타 게임 이미지는 저장하지 않았다.

레이어 순서는 `hair_back → body → hair_front → katar → grip`. 모두 전체 캔버스에 놓이며 보이는 픽셀을 분리한 결과다. 가려진 면까지 복원한 교체용 리그는 아니다. `pose.json`의 손·칼끝·머리 좌표는 캔버스 좌표이고 카타르 각도는 오른쪽 0°, 아래 방향 양수다. 레이어 검수 중 잘못 분류된 머리/칼날 경계 픽셀을 수정하고 칼끝을 실제 날 끝으로 재측정했다.

**검증:** 캔버스, 키, 머리 폭, 발 위치, 알파 0/255, 머리 정확히 4색, 레이어의 빈 파일 여부, 합성 결과의 바이트 일치, 최근접 확대, 비교판 배율, 서로 다른 생성 원본을 확인했다(`validation.json`). 지정 폴더 밖 기존 파일 12,895개는 SHA256이 유지됐다. src 변경·커밋·푸시 없음.
