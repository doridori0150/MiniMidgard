# 걷기 8장 제작 계획

## 사용자 말 (그대로)
- "모션은 최소 6~8장은 써야 할 거 같아."
- "앞쪽 지지발과 뒷쪽 발이 흔들려서 캐릭터 전체가 흔들려 보여."
- 그림 규칙 세 가지:
  1. 등신대, 컨셉 스타일, 전반적인 크기 영역을 맞출 것
  2. 레퍼런스를 체크할 것
  3. 스프라이트 애니메이션을 사전에 어떤 동작을 할지 고려하여, 1장씩 생성하고, 연결할 것

## 기준과 순서

현재 요청은 REQUEST_WALK_INBETWEENS.md에 원문 그대로 보존한다. 이전 PLAN.md의 통과 높이와 사이 장 제외 조건은 이번 요청으로 대체한다.

승인된 idle를 매 생성에 외형 기준으로 재첨부한다. 승인 접지 두 장은 수정하지 않는다. 기존 통과는 다리 역할만 참고하고 rejected/walk_previous/에 사유와 함께 보존한다. 첨부 RO 시트에서 교차 보행과 접지→내려앉음→통과→올라섬 리듬만 관찰한다. 타 게임 픽셀 및 첨부 파일은 저장하지 않는다.

재생 순서: walk_1 → walk_5 → walk_2 → walk_6 → walk_3 → walk_7 → walk_4 → walk_8. 각 90ms, 총 720ms, dx=dy=0. 시트에는 이 8장만 넣고 기준 idle 칸을 추가하지 않는다.

|순서|폴더|정수리 y|지지발 계획|
|---:|---|---:|---|
|1|walk_1_contact_near|130|원본 보존, 가까운 발 141..144|
|2|walk_5_down_near|132|가까운 발, 무릎 굽힘, 바닥 접촉 중심 137.5|
|3|walk_2_pass_near|131|가까운 발, 먼 발 통과, 중심 132.5|
|4|walk_6_up_near|128|가까운 발 발끝, 먼 발 전방 공중, 중심 127.5|
|5|walk_3_contact_far|130|원본 보존, 먼 발 137..141|
|6|walk_7_down_far|132|먼 발, 무릎 굽힘, 중심 134|
|7|walk_4_pass_far|131|먼 발, 가까운 발 통과, 중심 129|
|8|walk_8_up_far|128|먼 발 발끝, 가까운 발 전방 공중, 중심 124|

제자리 걷기의 접지발은 같은 발을 연속 추적한다. 요청의 약 15px 균등 후진을 접지 이후 세 구간에서 약 5px씩 적용한다. 부츠 모양과 발끝 전환에 따른 바닥 접촉 폭 차이는 실제 측정값으로 기록한다. 매 장 바닥 y=223을 지키고 몸 높이는 관절 그림에 반영한다.

한 장 생성 → 정규화·레이어 분리 → 직전 장과 원화 외형·정수리·지지발·손 역위상 대조 → 다음 장 순서로 진행한다. 외형 기준을 새 생성물로 바꾸지 않는다. 접지 그림 사이에 돌아오는 머리 중심도 고정하여 좌우 튐을 막는다. 256×240, 기준점 (128,224), 머리 60px 이하, 실제 알파, 기존 5개 레이어 순서를 유지한다.

생성 원본과 탈락 결과를 보존하고, 8장 시트·4배 확대·90ms 미리보기·실측 JSON·NOTES를 만든다. 외부 파일 및 보호 포즈의 SHA256을 전후 비교한다. src, 커밋, 푸시는 다루지 않는다.
