# 휘두름·접촉 뒷다리 수정 사전 계획

## 사용자 말 (그대로)
- "어쌔신은 3번째 이미지인가에서 뒷발이 사라졌어."
- 그림 규칙 세 가지:
  1. 등신대, 컨셉 스타일, 전반적인 크기 영역을 맞출 것
  2. 레퍼런스를 체크할 것
  3. 스프라이트 애니메이션을 사전에 어떤 동작을 할지 고려하여, 1장씩 생성하고, 연결할 것

## 고정 사항과 작업 순서
1. 승인 idle는 매 생성의 외형·비례·팔레트 참조. 기존 정점의 뒷다리는 두께와 부츠의 동작 참조. 첨부 이미지 자체를 복사하지 않는다.
2. 먼저 휘두름 한 장을 생성한다. 골반→허벅지→무릎→정강이→부츠를 body 층에 이어 그리고 정점과 접촉 사이의 기울기를 사용한다. 부츠 뒤쪽 x105, 밑창 y223. 잔상은 katar 층 그대로 두고 필요한 경우 하단 경계만 조정한다.
3. 생성 결과에서 뒷다리 영역만 승인 원본 body에 합성한다. hair_back/hair_front/grip과 앞다리·상체·팔은 원본 픽셀을 잠근다. 정점→휘두름을 실제 크기 및 확대에서 대조한 뒤 다음 장에 착수한다.
4. 접촉 한 장을 생성한다. 직전 수정 휘두름과 원래 정점에 이어지는 지지 다리, 읽히는 무릎, 최소 8px 부츠. 천 끝은 정강이·부츠를 가리는 경우에만 들어 올리거나 줄인다. 무기 최전방 도달과 앞다리는 유지한다.
5. 이전 두 폴더를 지정된 rejected 이름으로 이동하고 사유 1줄 보존. 다른 장·idle·walk·조립표·src는 변경하지 않는다.
6. 공격 시트 두 크기와 side_by_side_attack만 재구성한다. 보호 픽셀·부츠 범위/높이·잔상 금지 구역·다리 연결·외부 파일 해시를 검사하고 NOTES에 실제 측정과 생성/탈락 목록을 추가한다.

요청 원문 전체는 REQUEST_SWING_BACKLEG.md에 그대로 보존한다. 내장 image_gen으로 그림을 만들고 기존 Node 픽셀 도구로 영역 합성 및 검증한다.

## 휘두름 검수 완료 후 접촉 착수
정점→수정 휘두름→원래 접촉을 backleg_sequence_review.png에서 비교했다. 휘두름 뒷부츠는 y223 x105–116, 잔상 금지 구역 0px. 몸 층에 허벅지–무릎–정강이–부츠가 연결되며 잔상은 그대로 유지한다. 이를 직전 동작 참조로 접촉 한 장을 생성한다.
