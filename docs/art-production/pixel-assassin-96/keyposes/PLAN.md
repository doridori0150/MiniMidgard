# 96px 어새신 키포즈 제작 계획

사용자의 말과 그림 규칙 세 가지는 REQUEST.md에 원문 그대로 보존한다.

1. 승인된 96px 대기 원화를 모든 생성에 다시 첨부한다. 새 포즈를 다음 생성의 외형 참조로 사용하지 않는다.
2. 대기 → 걷기 접지(가까운 발) → 통과(가까운 발) → 접지(먼 발) → 통과(먼 발) → 공격 준비 → 정점 → 휘두름 → 접촉 → 회수 순으로 한 장씩 제작한다.
3. 각 장의 실루엣, 머리 크기, 근접 손 카타르, 발 접지를 확인하고 이전 장과 연결을 대조한 후 다음 장을 제작한다.
4. 걷기 접지는 통과보다 정수리가 3px 낮다. 제자리 걸음이며 카타르 손은 가까운 다리와 반대로 움직인다. 중간 프레임과 애니메이션은 만들지 않는다.
5. 공격은 승인된 48px 동작 역할을 읽고 96px 기준 외형으로 제작한다. 준비·정점은 뒤로 당긴 카타르, 휘두름은 넓은 호, 접촉은 가장 먼 칼끝, 회수는 낮은 자세에서 일어나기 시작하는 동작이다.
6. 캔버스 256×240, 발 기준 (128,224), 맨 아래 223행. 공격의 뒤쪽 접지발 뒤끝 x=105를 유지한다. 대기 내쉬기의 발은 기준 원화와 픽셀 단위로 동일하게 보존한다.
7. 생성 결과는 최근접 샘플링, 팔레트 정규화, 실알파 정리, 보이는 픽셀의 다섯 레이어 분리 후 측정한다. 정규화와 생성 자체의 차이는 기록한다.
8. 각 포즈의 레이어·합성·4배 확대·좌표 JSON, 동작별 비교 시트, 구작 공격×2 비교, NOTES 및 검증 결과를 이 폴더에만 저장한다. 첨부 원본을 복사하지 않으며 RO 이미지 파일을 저장하거나 픽셀을 가져오지 않는다.

## 참조 대조

- 96px 승인 원화: 머리 폭 55px, 정수리 y=128, 높이 96px, 뒤쪽 발 x=105. 얼굴·마스크·백금 머리·가는 V 테두리 조끼·남색 천 두 갈래·가까운 손 카타르 유지.
- 승인된 48px 공격: 준비 → 낮은 정점 → 넓은 휘두름 → 전방 접촉 → 회수.
- 제공된 RO 시트: walk의 교차 걸음, w-attack1의 준비·체중 이동·호를 그리는 절단·회수 순서만 관찰했다. 체형·팔레트·픽셀은 사용하지 않는다.
