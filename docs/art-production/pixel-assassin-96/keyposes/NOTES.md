# 어새신 96px 걷기 — 다리 6장 수정

현재 요청은 `REQUEST_WALK_LEGS.md`이며 원문을 그대로 보존했다. 접지 2장은 그대로 두고 나머지 6장의 다리만 교체했다. 이전의 '반 주기 15px' 조건은 폐기하고 다음 접지를 포함한 후진 거리로 검수했다. 이전 기록은 `rejected/walk_legs_previous/NOTES.md`에 있다.

## 사용자 말 (그대로)
- "모션은 최소 6~8장은 써야 할 거 같아."
- "앞쪽 지지발과 뒷쪽 발이 흔들려서 캐릭터 전체가 흔들려 보여."
- 그림 규칙 세 가지:
  1. 등신대, 컨셉 스타일, 전반적인 크기 영역을 맞출 것
  2. 레퍼런스를 체크할 것
  3. 스프라이트 애니메이션을 사전에 어떤 동작을 할지 고려하여, 1장씩 생성하고, 연결할 것

## 장별 실제 좌표와 보존

중심 x는 **223행에서 해당 발의 왼쪽·오른쪽 불투명 끝점의 평균**이다. 원본 접지의 0.5는 실제 측정값이며, 요청서의 정수 표기를 맞추려고 접지를 수정하지 않았다.

## 사전 계획, 한 장씩 제작·대조

`PLAN_WALK_LEGS.md`를 작성하고 승인 idle와 현재 걷기를 확인했다. idle는 외형·등신대·팔레트 기준으로 매 생성마다 첨부했다. 현재 걷기에서 머리·얼굴·상체·팔·카타르·허리천을 잠갔다. 새 그림을 외형 기준으로 대체하지 않았다. 첨부 참조 이미지를 이 폴더에 복사하지 않았고 타 게임 이미지도 저장하지 않았다.

1. 승인 접지 1 확인 → 내려앉음 2 생성·합성·대조: x134, 굽힌 지지 무릎과 뒤에서 들리는 발.
2. 통과 3 생성·합성·직전 장 대조: x125, 공중 다리가 지지 다리를 앞질러 감.
3. 올라섬 4 생성·합성·직전 장 및 접지 5 대조: x117, 뒤꿈치를 든 발끝 지지와 전방 공중 발.
4. 승인 접지 5 확인 → 내려앉음 6 생성·합성·대조: x132, 정수리132를 유지하며 지지 무릎 압축.
5. 통과 7 생성·합성·직전 장 대조: x125, 가까운 공중 발이 전방 통과.
6. 올라섬 8 생성·합성·대조: 첫 시도에 중복 무기·천 잔상이 있어 탈락. 승인 원본에서 다시 생성하고 x118 및 첫 접지의 뒤 먼 발112.5에 연결.
7. 전체 시트에서 동작 순서와 크기를 재검수하고, 허리천 경계와 앞쪽 남색 천의 보호 마스크를 보강했다. 모든 다리 밖 픽셀을 원본과 다시 비교했다.

## 산출물·재현·검증

각 폴더는 256×240 캔버스, 원점(128,224), 5개 레이어와 합성·4배 확대·pose.json을 유지한다. 생성물은 최근접 축소, 알파160 이진화, 승인 idle 팔레트 정규화 후 **다리 마스크 안에만** 합성했다. 지지 무릎 아래 발 위치를 목표에 등록하고 홀수 밑창 폭으로 정수 중심을 맞췄다. 생성 소스의 상체는 사용하지 않았다. 머리·무기·손 4개 레이어는 원본 파일 그대로이며 몸 레이어에서도 다리 마스크 밖은 투명 픽셀까지 그대로다. 원래 허리천과 남색 앞자락의 보호 마스크도 각 sources에 저장했다.

- `keyposes_walk.png`: 2048×240, 요청한 재생 순서 8장.
- `keyposes_walk_4x.png`: 8192×960, 최근접 4배 확대.
- `review_walk_3x.png`: 위 1~4, 아래 5~8의 확대 검수 시트.
- `walk_preview.apng` / `walk_preview.html`: 8장, 장당90ms, 총720ms, 전체 프레임 위치 보정 없음.
- 재합성: `node docs/art-production/pixel-assassin-96/keyposes/build_walk.mjs <폴더명>`.
- 시트·미리보기 갱신: 같은 폴더의 `sheets_walk.mjs`, 이어서 `animate_walk.mjs` 실행.
- 검증: `node docs/art-production/pixel-assassin-96/keyposes/verify_walk.mjs`.
- 검증 결과: `validation_walk_legs.json` 및 최신 `validation_walk.json`. 실제 발 좌표, 다음 접지 포함 이동량, 정수리, 레이어 재합성, 알파, 시트 순서, APNG의 각 프레임 픽셀·시간, 다리 밖·허리천 보호 픽셀, 접지·대기·공격·폴더 외부 파일과 이전 폴더 SHA256을 검사한다.

정적 프레임·연결 시트 시각 검수와 APNG 전 프레임 검증을 수행한다. 최종 미술 승인은 사용자 판단이며 브라우저에서의 실시간 재생 검수는 별도로 수행하지 않았다. `src/` 변경, 커밋, 푸시는 하지 않는다.

최종 검증 통과: 폴더 밖 15,183개 파일 변경 없음, 보호된 접지·대기·공격 96개 파일 일치, 이전 여섯 폴더 78개 파일 보존 확인. 여섯 목표 좌표 모두 일치하며 다리 밖·보호 천의 변경 픽셀은 0개다. 생성 7장 / 채택 6장 / 새 탈락 1장. 커밋·푸시 없음.
