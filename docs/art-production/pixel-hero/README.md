# 쿠키 픽셀 영웅 시험

`minimidgard.pixel/1` 납품. `manifest.json`을 기준으로 몸 14장, 검 14장, grip 14장, 헤어 18장(3스타일 × 3자세 × 앞/뒤)을 읽습니다.

기존 B 여검사의 의상·팔다리 포즈를 1px 격자에 맞춰 축소한 뒤, 팔레트 제한·불투명 외곽선 정리·잔여 머리 제거·목 연결·공격 준비 손바닥 보정을 적용했습니다. 얼굴과 짧은 기본 머리는 `up`, `hurt`, `down` 원본을 각각 한 번 제작하고 정수 좌표에 그대로 붙였습니다. 헤어·검·손가락은 네이티브 해상도에서 직접 그렸습니다. 이미지 생성 모델은 사용하지 않았으며, 제작 지시 기록은 `prompts/production.txt`, 실제 제작 코드는 `source/build.py`입니다.

- 칸 128×120, 발 기준 (64,112), 기본 idle 몸 높이 76px. 동작에 따른 높낮이 변화는 유지했습니다.
- 몸 14장의 합집합 팔레트는 20색. 알파는 0/255이며, 4개 헤어 키는 기본 머리와 헤어 레이어에만 사용합니다. 재색칠할 때 **몸 안의 기본 머리도 함께** 치환합니다.
- 모든 헤어 타일은 96×96, pivot은 (48,48). `head.point - pivot`에 놓습니다. 쓰러짐 헤어는 바닥에 눕도록 별도 정리했습니다.
- 검은 가까운 쪽 손에 있고 모두 `z: front`. 앉기·쓰러짐은 검과 grip이 빈 PNG이며 `visible: false`입니다.
- 애니메이션 7개의 시간과 loop는 기존 B manifest와 같습니다. attack_1은 100–180ms이며, 요청된 접촉 시각 140ms를 포함합니다.

`verification/review.png`(4배, 7×2), `hair-swap.png`(5포즈 × 3스타일 × 갈색/검정/분홍), `body-only.png`, `game-size.png`를 직접 열어 확인했습니다. 초기 검수에서 발견한 남은 머리 윤곽 조각, 쓰러짐 헤어 잘림, 공격 준비 손바닥의 결손을 수정하고 재검수했습니다. `game-size.png`는 검수용으로 그린 필드 배경에 1배/2배로 합성한 이미지이며 게임 실행 캡처는 아닙니다. `play-1x.gif`, `play-4x.gif`는 대기·걷기·공격·시전과 원래 프레임 시간을 담았습니다.

`verification/validation.json`에 PNG 60장의 SHA256과 검증 결과를 남겼습니다. 14개 머리의 픽셀 일치, 32색 이하, 알파, 헤어 전용 색, 레이어 경계, 손가락/검/손바닥 겹침, 동작 시간 및 GIF 시간을 통과했습니다. 현재 확인된 규격 미충족 프레임은 없으며 `rejected/` 대상도 없습니다. 실제 게임 연결과 런타임 검수는 요청서에 지정된 후속 작업입니다. 기존 자산·게임 코드는 수정하지 않았고 커밋·푸시는 하지 않았습니다.

재생성/검증(Python + Pillow + NumPy):

```sh
python source/build.py
python source/validate.py
```

입력 파일 경로와 SHA256은 `source/provenance.json`, 사용한 의존성 버전은 `source/requirements.txt`에 기록했습니다.
