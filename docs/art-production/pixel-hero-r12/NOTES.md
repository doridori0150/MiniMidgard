# 쿠키 R12

시안 C의 크림색 단발·호박색 눈·남색/은색 의상과 약 2등신 비율을 유지했다. 공격은 **짧게 감기 → 칼 세우기 → 전방 사선 베기 → 끝 자세 → 회수 → 대기**, 여섯 장으로 새로 제작했다. 검 든 가까운 오른팔이 가슴 앞에서 연결되도록 했고, 손이 바뀌어 보이던 첫 복귀 시안은 제외했다.

- **90 / 40 / 60 / 100 / 70 / 70ms**, 총 **430ms**. `hitFrame: 2`는 0부터 세는 세 번째 장이며 시작 후 130ms에 진입한다. 큰 잔상은 타격 한 장에만 두고, 다음 장의 칼과 끝 자세를 조금 더 길게 보여준다.
- 복귀에서 대기로 검이 건너뛰지 않도록 **대기 4장도 갱신**했다. `attack_5`와 `idle_0`는 픽셀까지 같다. 호흡은 발을 고정하고 상체·머리 끝을 1px 움직이는 정도로 제한했다.
- **걷기 8장·피격 2장·쓰러짐 4장·앉기 1장**은 R10의 그림을 보존했다. 전체 패키지는 25장이다. 이번 새 공격/대기에 대한 검수와 기존 동작의 복사 검증을 구분했다.

## 사용

`manifest.json`은 **minimidgard.pixel/1** 형식이며 캔버스 128×120, 원점 `[64,112]`, 대기 캐릭터 높이 48px이다. 몸·앞/뒤 머리·검·손가락 레이어가 분리되어 있다. 머리는 기존 네 색 키만 사용하고, 새 몸·검에는 그 키 색이 섞이지 않도록 했다. 새 머리 포즈는 전체 캔버스 좌표와 포즈별 `pivot: [0,0]`을 사용한다. 기존 렌더러가 이미 지원하는 방식이다. 기본 C 단발(`wavy_p2`)만 포함하며 다른 헤어스타일은 새로 제작하지 않았다.

- `attack_1x.gif`, `attack_4x.gif`: 실제 공격 시간만 반복. 1×는 원본 게임 픽셀 크기, 4×는 최근접 확대.
- `idle_1x.gif`, `idle_4x.gif`: 새 대기. `walk_*.gif`: 보존한 걷기 확인용.
- `review.html`: 파일을 브라우저로 열어 재생/장별 확인. `verification/attack_context_4x.gif`는 대기와 공격 연결 보기.
- `attack_contact_sheet.png`: 0~5번 프레임과 지속 시간. `composite/`: 합성 PNG.

## 제작·검수

내장 **image_gen**으로 한 장씩 생성했다. 선택한 원본 6장과 픽셀 샘플은 `source/`, 실제 프롬프트 7회와 제외 기록은 `PROMPTS.json`에 있다. 픽셀 격자 샘플링·팔레트 정리·마스크 분리·최근접 크기 통일을 적용했다. 준비 장의 검에 가려진 머리 부분은 주변 머리 픽셀 색으로 뒤 레이어를 보완했다. 다른 게임의 그림은 사용하거나 저장하지 않았다.

작은 크기의 연속 자세, 오른팔과 검 연결, 색 변경/검 숨김 시트를 직접 살폈다. `validate.py`의 **424개 검사**를 통과했고, macOS ImageIO로 GIF **36프레임 전부**를 독립 디코딩해 시간·크기·합성 PNG와 픽셀 일치를 확인했다. 결과는 `verification/validation.json`, `verification/gif_validation.json`에 있다. 브라우저 자동 재생의 화면 검수는 도구 접근 제한으로 수행하지 못했다. **게임 실행 적용·전투 판정 체감 검증은 하지 않았다.**

재생성: `python3 docs/art-production/pixel-hero-r12/build.py` → `python3 docs/art-production/pixel-hero-r12/validate.py`. 빌드는 보존 동작을 R10에서 읽는다. 패키지의 manifest 및 이미지 경로는 모두 R12 안에서 완결된다. 기존 폴더·`src/` 수정, 커밋·푸시는 하지 않았다.
