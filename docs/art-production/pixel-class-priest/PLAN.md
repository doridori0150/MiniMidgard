# 프리스트 제작 계획

여성 `priest_female_p2`, `priest_crown_braid_p2`, 철퇴 `mace`. 상아색 왕관 땋은머리와 짧은 뒷머리, 짙은 자주색 예복 위 상아색 어깨 케이프와 금테 스톨, 청록 보석, 짧은 갈색 부츠. 별도 모자 없이 24px 두상과 24px 몸, 대기 48px. 오른쪽 3/4, 가까운 화면 오른쪽 손이 철퇴를 계속 잡고 빈손이 기도·축복을 한다.

원화는 내장 imagegen으로 한 장씩 제작한다. 다음 장 전에 직전 장의 손, 머리 크기, 의상, 발 이동, 철퇴를 확인하고 기록한다. 재사용하는 준비·유지·회수 자세는 명시하며 프레임 수를 늘리기 위한 단순 복제 걷기는 금지한다. 등록은 최근접 축소와 색상 제한, 원화 기반 레이어 분리만 사용한다.

## 기본 동작
- 대기: 편안한 정지 → 작은 호흡 → 정지.
- 걷기 8장: 가까운 발 접지 → 하중 → 반대 발 통과 → 반대 발 전진 → 반대 발 접지 → 하중 → 가까운 발 통과 → 가까운 발 전진. 발목과 예복 자락으로 교대를 읽게 한다.
- 공격 8장: 어깨 준비 → 뒤로 들어올림 → 정점 → 전방 하강 → 낮은 타격 → 버팀 → 회수 → 대기. 4번 타격, 준비 300ms / 총 650ms 근처.
- cast_start: 빈손을 가슴으로 모음 → 철퇴 손 옆에서 기도. cast: 기도 → 작은 호흡 → 기도. 루프 이음 고정.
- 피격: 뒤로 젖힘 → 회수 → 대기. 쓰러짐: 피격 → 무릎 → 옆으로 누움. 앉기: 다리를 옆으로 접음.

## 스킬 동작과 전체 매핑

|skill_bless|blessing, increase_agi, impositio, suffragium, aspersio, kyrie|기도 → 빈손을 들어 축복 → 전방으로 내려줌 → 대기|

|skill_light|holy_light, turn_undead|가슴에 모음 → 빈손을 곧게 뻗어 정화 → 버팀 → 회수|

스킬은 0.5~1초. 대상에게 효과가 전달되는 모션은 앞 장 합계 130ms에 hitFrame. 공통 요청서에 따라 아군/파티 버프와 자기 버프는 hitFrame 없음. 부활·회복·약화·공격·설치·이동·제작은 효과 전달 프레임에 hitFrame. 철퇴 2연타의 hitFrame은 첫 타격이며 두 번째는 몸 동작만 표현하고 추가 런타임 피해 이벤트를 만들지 않는다. 마법 이펙트는 그리지 않는다.
