# ② 남자 어새신 층 조립 대기 컨셉

요청한 대기 1장과 분리된 7개 레이어를 제작했다. 사용자 발언과 그림 규칙 세 가지는 요청 문서를 복사한 `REQUEST.md`에 수정 없이 보존했다. 착수 전 계획은 `PLAN.md`에 있다. 컨셉의 최종 미술 승인은 사용자 검토 단계이며, 모션 제작이나 게임 적용은 이번 결과에 포함하지 않는다.

## 요청한 검사 — 항목마다 한 줄
- 정수리 y=128, 턱 y=165, 머리 높이 38px, 머리카락 포함 폭 40px; 전체 높이 96px, 머리 비중 39.58%로 약 2.53등신.
- 발 마지막 줄 y=223: 가까운 발 x=111–121, 먼 발 x=130–143; 공통 발 기준점 (128,224).
- 7개 제작 레이어 모두 256×240 RGBA이며 알파는 0/255만 사용한다; 4배 확대판과 나열판은 검토용 파생 이미지다.
- `composite.png`는 body → outfit → head → near_arm → outfit_arm → weapon(front) → grip 순서의 픽셀 합성과 완전히 일치한다.
- 겉옷이 덮어야 할 몸(y≥166)에 남은 노출 픽셀 0개, 가까운 팔 피복 누락 0개, 두 허리 천을 제외한 몸 윤곽 변경 0개, 발 점유 범위 변경 0개.

추가 검사: 머리 pivot과 목 위 중심은 모두 (126,164), 목 위 2줄에서 머리 밖에 남은 픽셀 0개. 머리카락 키색은 `#faf0d7 #e1cdb8 #b49b91 #49342f` 네 가지이며 이탈 픽셀 0개. 흰 눈 반사광은 각 눈 1px씩 총 2px. 카타르 grip=(129,187), tip=(152,187), angle=0°, z=front. 숫자는 `concept/assassin_male_idle/validation.json`에 기록했다.

## 시각 검수와 순차 제작

첨부 1·2에서 약 2.5등신, 단순한 실루엣, 오른쪽 3/4 시점, 도트 경계를 확인했다. 승인 아트에서는 백금색 머리·호박색 눈·마스크·조끼·스카프·허리 천·카타르만 디자인 기준으로 삼았다. PixelLab 시험은 표정과 셀 명암의 방향을 참고했다. 네 참고 이미지는 기존 위치에서만 확인했으며 이 폴더에 복사하지 않았다.

맨몸 비율·접지를 확인한 뒤 가까운 팔을 분리했다. 그 몸 위에서 머리 크기와 목 접합을 확인한 다음 겉옷을 입혔고, 겉옷이 몸과 발을 바꾸지 않는지 확인한 뒤 카타르를 제작했다. 몸통에서 팔에 가려지는 작은 내의 영역은 같은 행의 내의 색으로 연결해 머리·옷을 갈아 끼울 수 있게 했다. 얼굴과 마스크는 목 없는 단일 머리 PNG다. 허리 천 두 자락은 겉옷의 일부이며 선택 레이어인 head_back은 필요하지 않았다.

96px 확대판, 59px 게임 크기, 70px 폰 비교 크기, 각 층 단독 나열을 눈으로 확인했다. 작은 크기에서도 백금색 머리·마스크·두 남색 천·앞으로 나온 카타르를 구분할 수 있다. 흰 눈 반사광과 작은 황동 장식은 축소 시 일부 소실된다. 실제 폰 기기나 게임 런타임에 적용한 검수는 아니며, 저장한 동일 크기의 정지 이미지 검수다. `concept/assassin_male_idle/preview.html`에서 밝은색·흙색·어두운색 배경과 왼쪽 반전을 비교할 수 있다.

## 생성·채택·폐기

내장 `image_gen`을 총 5회 호출했다. 생성 이미지 5개 중 채택 원본 4개, 폐기 원본 1개다. 생성 원본과 실제 프롬프트는 각 레이어 옆 `sources/`에 보존하고 gitignore 처리했다. 새 그림을 코드 도형으로 대체하지 않았으며, 생성된 그림을 최근접 축소·좌표 정렬·팔레트 정리·마스크 분리·합성해 납품 규격에 맞췄다.

| 생성 이미지 | 판정 | 근거 및 사용처 |
|---|---|---|
| `bodies/male/idle/1_base/sources/body-v1.png` | 폐기 | 다리가 길고 양쪽 발바닥 높이가 달라 대기 접지·비율 기준에 맞지 않았다. |
| `bodies/male/idle/1_base/sources/body-v2.png` | 채택 | 이전 몸을 편집해 비율과 같은 발바닥 높이를 개선. `body.png`, `near_arm.png`로 분리. |
| `heads/assassin_male/sources/head-v1.png` | 채택 | 백금색 곡선 앞머리·호박색 눈·마스크. 38×40px 범위와 키색으로 정리해 `front.png` 제작. |
| `outfits/assassin_male/idle/1_base/sources/outfit-v1.png` | 채택 | 직전 몸을 편집 대상으로 의상 생성. 기존 몸 마스크에 정확히 맞춰 `outfit.png`, `outfit_arm.png` 제작. |
| `weapons/katar/idle/1_base/sources/weapon-v1.png` | 채택 | 넓은 삼각 칼날과 펀치형 손잡이. `weapon.png`로 정리하고 직전 장갑에서 손가락 덮개 `grip.png` 분리. |

파생본 수정: 초기 머리 색상 정리본에는 순백 픽셀이 6개여서 흰자 부분을 아이보리로 바꾸고 반사광 2개만 남겼다. 턱 외곽 1px를 정리해 목 위 2줄을 모두 덮었다. 카타르 끝점 메타데이터는 축소 후 실제 마지막 불투명 픽셀 (152,187)에 맞췄다. 모두 수정 후 재검증했다. 이 수정은 추가 생성이나 사용자 되돌림으로 계산하지 않았다.

## 납품과 재검증

- 몸: `bodies/male/idle/1_base/{body.png,near_arm.png,pose.json}`
- 머리: `heads/assassin_male/{front.png,pivot.json}`
- 겉옷: `outfits/assassin_male/idle/1_base/{outfit.png,outfit_arm.png}`
- 무기: `weapons/katar/idle/1_base/{weapon.png,grip.png}`
- 합성·4배·층별 나열: `concept/assassin_male_idle/{composite.png,composite_4x.png,layers_4x.png}`

프로젝트 루트에서 `node docs/art-production/hero-layered/validate.mjs`를 실행하면 저장된 PNG와 검수 영역 정보를 다시 검사한다. 외부 패키지 및 비공개 sources 없이 검사할 수 있다. `prepare.mjs`는 로컬 생성 원본을 사용하는 규격 정리 기록이다. 요청 문서는 `cmp`로 원문 일치를 확인했다. `spec.json`과 요청 폴더 밖 파일은 수정하지 않았고, src 변경·커밋·푸시를 하지 않았다.
