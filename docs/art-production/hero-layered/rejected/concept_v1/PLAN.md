# ② 대기 컨셉 제작 계획

요청 원문과 사용자 발언, 그림 규칙 세 가지는 `REQUEST.md`에 그대로 보존했다. 기준 문서는 `../../art/PIPELINE_LAYERED.md`와 기존 `spec.json`이다.

1. 첨부 1·2의 2.5등신, 깨끗한 픽셀 외곽선, 부드러운 셀 명암을 확인한다. 승인 아트는 얼굴과 장비 디자인만, PixelLab 시험은 스타일 방향만 참고한다. 참고 이미지나 그 픽셀을 복제하지 않는다.
2. 전체 키 96px, 정수리 y=128, 발 마지막 줄 y=223. 머리는 약 38px, 목 위 2px 겹침. 캔버스 256×240, 발 기준 (128,224). 모든 레이어에 같은 좌표를 쓴다.
3. 몸과 가까운 팔을 먼저 만든다. 오른쪽 3/4, 편안한 대기, 양발 접지. 차후 들숨→기본→날숨 연결 시 발은 고정하고 몸통의 작은 변화만 허용하도록 설계한다. 이번에는 기본 1장만 제작한다. 공격 모션은 만들지 않는다.
4. 몸 검수 후 머리를 제작하고 목 접합을 검수한다. 머리 검수 후 겉옷을 몸에 맞추고 피복·발·실루엣을 확인한다. 그다음 가까운 주먹에서 앞으로 뻗는 카타르와 손가락 덮개를 제작한다. 매 단계 직전 결과를 보고 진행한다.
5. 지정한 층 순서로 합성한다. 원본·4배·층별 나열과 게임 크기 59px/폰 약 70px 미리보기를 확인한다. 숫자 검사는 시각 검수와 함께 기록한다.
6. 생성 프롬프트·원본은 각 층 옆 `sources/`에 보존하고 gitignore 처리한다. 제작물·검수 기록만 이 폴더에 쓴다. src 수정, 커밋, 푸시는 하지 않는다.

## 그림 규칙 세 가지
1. 등신대, 컨셉 스타일, 전반적인 크기 영역을 맞출 것
2. 레퍼런스를 체크할 것
3. 스프라이트 애니메이션을 사전에 어떤 동작을 할지 고려하여, 1장씩 생성하고, 연결할 것
