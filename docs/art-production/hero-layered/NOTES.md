# ② 체형 수정 대기 컨셉

요청 문서와 사용자 발언·그림 규칙 세 가지를 `REQUEST.md`에 원문 그대로 보존했다. 계획은 `PLAN.md`. 기본 대기 1장만 수정했으며, 몸 → 머리 부착 확인 → 의상 → 무기 배치 → 합성 순서로 직전 결과를 확인했다.

## 요청 검사 — 항목마다 한 줄
- 어깨 폭(양팔 포함) **34px**(y=169), 가슴 폭(팔 제외) **24px**(y=178), 턱 **y=166**, 엉덩이 **y=205**, 턱~엉덩이 **39px**, 다리 **19px**(엉덩이 경계 y=205부터 발 y=223까지 포함), y=214 양쪽 다리 폭 **9px / 9px**, 팔 폭 **7px / 7px**(y=180).
- 머리 중심 **x=128.5**, 몸통 중심 **x=125.5**: 보는 방향인 오른쪽으로 **3px** 앞섬; 머리 원본 대비 이동 (+7,+1), `head.point=(133,165)`.
- 턱이 옷깃 **y=164–166의 3줄**을 덮음(겹침 27px), 보이는 목 **0px**.
- 맨몸은 피부 3단+하이라이트와 단순 속바지뿐이며, 합성에서 옷 아래 몸·팔·손·머리 아래 얼굴 접합부의 피부 노출 **0px**; 승인 머리 PNG 자체의 얼굴은 그대로 유지.
- 발 y=223 범위 **x=114–123 / 130–140**, 모든 제작 레이어 알파 **0/255**, 합성=지정 순서의 레이어 스택 **일치**, 겉옷 미피복 몸 **0px**, 가까운 팔 미피복 **0px**, 허리 천을 제외한 몸 윤곽 차이 **0px**.

머리 `front.png`, 머리 pivot, 카타르 `weapon.png`·`grip.png`, `spec.json`은 수정 전 SHA256과 일치한다. 카타르는 PNG를 다시 그리지 않고 원본 grip (129,187)에서 새 손 (110,198)로 (-19,+11) 이동하여 합성한다. 끝점 (133,198), 각도 0°, 앞 레이어다. 변환값은 `layers.json`, 위치는 각 `pose.json`에 있다.

머리를 원본 그대로 1px 내렸으므로 정수리 y=129, 턱 y=166, 머리 높이 38px, **불투명 픽셀의 실제 전체 키는 95px**다. 요청의 정수리 y≈128 범위에서 하향 배치를 적용했다. 96px 기준 영역(y=128–223), 캔버스 256×240, 발 기준 (128,224), 59px/70px 표시 영역은 유지했다. 높이를 96px라고 잘못 보고하거나 머리 그림을 늘리지 않았다.

## 순차 제작 및 시각 확인

첨부 감사 이미지에서 두툼한 몸통, 짧고 굵은 다리, 턱과 어깨의 겹침을 확인하고 도깨비의세계 첨부는 그림체·체형만 참고했다. 외부 게임 캐릭터·옷·픽셀을 복제하지 않았다. 기존 컨셉의 백금색 머리, 눈, 마스크, 짙은 갈색 조끼, 황동 V자, 남색 스카프와 두 허리 천, 카타르 디자인을 유지했다.

첫 생성 맨몸을 최근접 부위별 축척해 어깨·가슴·팔·다리 규격을 맞추고 가까운 팔을 분리했다. 피부색 팔은 허리에 올리지 않고 양옆으로 내려 손을 엉덩이 가까이 두었다. 머리 부착 결과를 본 뒤 그 몸을 편집 입력으로 의상을 생성했다. 의상은 새 몸의 알파 마스크에 맞추고, 생성 중 이전 그림에서 잘못 따라온 은색 손잡이 모양은 가죽 허리띠 색으로 정리했다. 실제 카타르 원본은 마지막에 새 손 위치로 배치했다.

몸·의상·최종 확대판, 이전/수정 비교, 59px 게임·70px 폰 크기 정지 이미지를 눈으로 확인했다. 황동 V자와 남색 스카프, 카타르는 축소에서도 구분된다. 몸과 팔이 넓어지고 양발은 짧고 안정적으로 접지한다. 실제 게임 실행이나 폰 기기 검수는 이번 범위에 포함되지 않는다. 공격·추가 대기 프레임은 제작하지 않았다.

## 생성·채택·기각 이미지

이번 내장 `image_gen` 호출은 **2회**, 새 원본 채택 **2개**, 새 생성 기각 **0개**다. 이전 컨셉 1세트는 사용자 판정에 따라 보관했다. 생성 원본과 실제 프롬프트·가공 코드는 `sources/`에 있으며 참고 이미지의 복사본은 없다.

|---|---|

| `sources/outfit-v2-generated.png` | 채택: 새 몸에 기존 의상 재착장. 마스크·팔레트 정리 후 `outfits/assassin_male/idle/1_base/{outfit,outfit_arm}.png`로 제작. |

기각 사유는 `rejected/concept_v1/REASON.txt`에 요청 그대로 **"too thin, neck showing, head set back"** 한 줄로 보존했다. 이전 생성 과정의 원본·중간 결과도 같은 보관 폴더에 유지했다. 머리와 카타르 원본은 현재 경로에 그대로 있다.

## 재검증

`node docs/art-production/hero-layered/validate.mjs`로 검증한다. 검사기는 비공개 생성 원본 없이 제작 PNG·위치 정보·검수 영역을 읽고 치수, 이진 알파, 원본 보존 해시, 피복, 윤곽, 발, 합성 일치를 확인한다. 결과는 `concept/assassin_male_idle/validation.json`에 기록된다.

재조립 소스는 `sources/{build-v2,finish-v2,compose-v2}.mjs`; 순서대로 `node docs/art-production/hero-layered/prepare.mjs body`, `outfit`, `composite`를 실행한다. 단계마다 이미지를 확인한 뒤 다음 단계로 진행한다. `sources/`는 기존 gitignore 정책대로 로컬 보존한다.

이 작업의 프로젝트 파일 변경은 모두 `docs/art-production/hero-layered/` 안에서 수행했다. 참고 이미지 복사, `src/` 수정, 커밋, 푸시는 하지 않았다.
