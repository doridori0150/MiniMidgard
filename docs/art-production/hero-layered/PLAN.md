# ② 체형 수정 계획

사용자 원문은 REQUEST.md에 그대로 보존한다. 참고 3장은 원래 위치와 첨부에서만 확인하며 복제하지 않는다.

1. 이전 몸·옷·무기 위치·합성을 rejected/concept_v1에 보존한다.
2. 머리와 카타르 원본은 그대로 유지한다. 새 몸은 피부 3단+하이라이트, 속바지뿐인 중립 대기 자세로 만든다. 어깨 32–34, 가슴 24–26, 다리 18–19, 팔 6–7px를 기준으로 한다.
3. 기본 대기 1장만 만든다. 후속 들숨·기본·날숨은 발과 손을 고정하고 몸통만 작게 움직일 계획이며 이번에는 제작하지 않는다.
4. 몸 한 장을 확인한 후 같은 몸에 기존 의상 디자인을 맞춘다. 머리 붙는 위치와 어깨 겹침, 손·카타르 위치를 검수한다.
5. 각 단계에서 직전 결과를 확인한다. 합성, 확대, 층별 나열, 게임 59px와 폰 70px 이미지를 만든 후 실측 검증한다.

## 그림 규칙 세 가지
1. 등신대, 컨셉 스타일, 전반적인 크기 영역을 맞출 것
2. 레퍼런스를 체크할 것
3. 스프라이트 애니메이션을 사전에 어떤 동작을 할지 고려하여, 1장씩 생성하고, 연결할 것
