# 축복 v2 사전 계획

사용자 원문과 그림 규칙은 REQUEST.md에 그대로 보존한다.

- 0 / 100ms: 승인된 시작 프레임을 그대로 보존.
- 1 / 140ms: 양 팔꿈치를 굽혀 두 손을 가슴 앞으로 올리며 가까워짐.
- 2 / 160ms: 가슴 앞에 두 손을 모아 기도. 철퇴는 모은 손에서 아래로 향하도록 유지.
- 3 / 100ms: 기도를 풀며 손과 철퇴를 원래 자리로 회수.
- 4 / 100ms: 승인된 대기 복귀 프레임 보존.

총 5장 600ms, hitFrame 없음. 128×120, 발 (64,112). 얼굴·머리·하반신은 승인 픽셀을 보존하고 팔·손·철퇴 이동 영역만 변경. 머리 4색 유지. 빛기둥·깃털은 게임 이펙트이므로 그리지 않는다.

첨부 RO 시트의 마지막 w-attack3/cast 행에서 팔을 들어 가슴 앞에 모으는 자세를 확인했다. 외형은 승인된 프리스트만 따른다. URL은 조회 오류여서 재생을 검증했다고 하지 않는다.

각 프레임은 직전 그림을 확인한 뒤 별도로 제작한다. 생성 입력에는 항상 승인 원본과 RO 레퍼런스를 사용하고 새 프레임을 스타일 참조로 쓰지 않는다.
