# 프리스트 축복 v2

`priest_female_p2` / `skill_bless`만 납품한다. 두 손을 가슴 앞에 모아 기도하고 짧게 회수한다. 5장, 100·140·160·100·100ms, 합계 600ms. 128×120, 발 기준 (64,112), `hitFrame` 없음. 빛기둥·깃털은 게임이 따로 그리므로 스프라이트에 넣지 않았다.

## 사용자 요청 (원문)
> 축복은 두빛 기둥 받으면서 앞으로 손 모아서 기도 하는 느낌으로하자.
> mmo다 보니 모션이 길면 안되니까.

## 사용자의 그림 규칙 세 가지
1. 등신대, 컨셉 스타일, 전반적인 크기 영역을 맞출 것
2. 레퍼런스를 체크할 것
3. 스프라이트 애니메이션을 사전에 어떤 동작을 할지 고려하여, 1장씩 생성하고, 연결할 것 (다음 그림을 그리기 전에 이전 그림을 체크해서 연결되게)

## 계획·레퍼런스·장 사이 검수

사전 [PLAN.md](PLAN.md): 시작 유지 → 손 모으기 → 기도 정점 → 회수 → 대기. 첨부 RO 시트 마지막 `w-attack3 / cast` 행의 가슴 앞 손 모으기와 팔꿈치 접기를 참고했다. RO 외형·장비·색은 사용하지 않았다. 요청 URL은 열기 오류로 실제 재생을 확인하지 못했으며, 첨부 시트를 확인 근거로 사용했다.

0번을 확인한 뒤 1번 생성·축소·합성·검수, 1번 확인 뒤 2번, 2번 확인 뒤 3번 순서로 진행했다. 각 생성에는 승인 원본 2개와 RO 시트를 다시 첨부했다. 새 프레임을 다음 생성의 스타일 참조로 사용하지 않았다. 0→1에서 손이 가슴으로 모이고, 1→2에서 손이 올라가며 팔꿈치가 접히고, 2→3에서 손이 떨어져 내려오는 것을 직접 확인했다. 3→4 비교와 최종 접촉 시트도 확인했다. 세부 기록과 비교 PNG는 `verification/`에 있다.

0·4번 레이어는 승인 파일과 바이트 단위로 동일하다. 1·2·3번은 승인 0번의 머리·얼굴·하반신 픽셀을 유지하고 몸의 y=88–100 구간 및 손·철퇴 레이어를 교체했다. 공통 축척 48/550, 최근접 샘플링, 기존 팔레트, 이진 알파를 사용했다. 프레임마다 크기를 늘이거나 줄이지 않았다. 머리 앞뒤와 키 색 4개는 그대로다.

## 납품·검사

- [미리보기](preview.html), [새 판 1×](skill_bless_1x.gif), [새 판 4×](skill_bless_4x.gif), [현재 판/새 판 비교](old_vs_v2_4x.gif), [접촉 시트](skill_bless_contact_sheet.png).
- `manifest.json`: `minimidgard.pixel/1`, 레이어 경로·pivot·SHA256. `skill_bless.png`: 투명 5칸 시트. GIF는 검토용 반복이며 실제 애니메이션은 한 번 재생한다.
- 내장 `image_gen.imagegen`으로 수정 프레임 3개를 각각 생성했다. 정확한 백엔드 모델명은 도구가 제공하지 않는다. 원본은 `authored/`, 실제 프롬프트는 `prompts/`, 입력 해시는 `references/hashes.json`, 변환 기록은 `TRANSFORMS.json`, 전체 납품 목록·해시는 `FILES.json`이다.
- 공방 검사: **오류 0, 주의 1**. 주의는 그대로 보존한 마지막 승인 프레임의 기존 분리 픽셀 3개(4px)다. 새 3개 프레임에는 이 경고가 없다. `verification/asset-check.json` 참조.
- 자체 검사: 25개 RGBA 레이어, 머리 4색, 보호 픽셀, 레이어 재합성, 해시 통과. GIF 4개는 독립 LZW 디코더로 5장·600ms·배율·모든 픽셀을 확인했다. `verification/validation.json` 참조.
- 외형은 제작자가 정지 프레임과 연결 시트로 검토했다. **게임 무대 촬영과 사용자 승인은 미실시**다. 오프라인 픽셀 차이 수치는 게임 무대의 20% 검사 결과로 간주하지 않는다.

프로젝트 파일은 이 납품 폴더에만 작성했다. `src/`, 기존 승인 납품, 커밋·푸시는 변경하지 않았다. 단, 내장 이미지 도구가 원본 자동 캐시를 `~/.codex/generated_images/`에도 저장했으므로 파일시스템 전체 기준으로 폴더 밖 쓰기가 전혀 없었다고 할 수는 없다. 이 자동 저장 위치는 도구 호출에서 지정할 수 없었다.

재검사: 저장소 루트에서 `python3 -B docs/art-production/pixel-priest-bless-v2/validate.py`. 공방: `node ../asset-kit/tools/check.mjs --root docs/art-production/pixel-priest-bless-v2 --manifest workshop-manifest.json`. 빌드 캐시와 zip은 납품에 포함하지 않았다.
