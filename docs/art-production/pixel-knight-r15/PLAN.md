# R15 제작 전 계획

2등신·48px 대기 키·128×120 캔버스·(64,112) 기준점·기존 금발/청록 망토/은색 갑옷/한손검을 유지한다. 공격 외 모든 레이어와 동작은 R14 그대로 복사한다.

첨부한 RO 여성 기사 남동 공격 및 남성 동쪽 공격을 확인했다. 원본 그림은 저장하거나 픽셀을 사용하지 않는다. 공개 렌더러는 웹 도구에서 접근 실패, 내장 브라우저도 이용 불가이므로 제공된 실제 클라이언트 프레임 분해표를 시각 기준으로 삼는다.
