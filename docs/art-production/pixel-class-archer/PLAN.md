# 궁수 제작 전 계획

남성 궁수 archer_male_p2 한 직업만 제작한다. 2등신, 대기 키 48px, 128×120 투명 캔버스, 발 기준점 (64,112), 오른쪽 3/4 시점. 짧은 옆가르마 머리, 굵고 곧은 눈썹, 속눈썹 꺾임 없는 눈, 숲색 짧은 튜닉, 황토색 스카프, 갈색 가죽 흉대·손목 보호구·부츠, 작은 등 화살통. 머리는 지정된 네 가지 키색으로 분리한다.

첨부 RO 궁수 시트에서 숨쉬기, 발 교차, 활 올림→귀 옆까지 당김→놓기→발사 자세 유지, 뒤로 젖힘과 뒤로 눕는 쓰러짐, 무릎을 접는 앉기를 확인했다. RO 원본은 저장하거나 픽셀을 복사하지 않는다. 쿠키 r12와 기사 r15는 크기·픽셀 밀도·등신대만 참조한다.

|동작|장수|시간(ms)|계획|
|---|---:|---|---|
|idle|3|280,280,280|아래로 활을 든 전투 대기, 1px 숨쉬기|
|walk|6|100×6|왼발 전진→통과→오른발 전진→통과, 같은 손의 낮은 활|
|attack|7|100,120,140,40,70,70,60|들기→절반 당김→완전 당김→발사→시위 진동→유지→회수|
|hurt|2|80,160|충격에 뒤로 젖힘→가벼운 회복|
|dead|3|100,160,1000|무릎 풀림→뒤로 기울어짐→뒤로 누워 정지|
|sit|1|1000|무릎을 접고 낮게 앉아 활을 같은 손으로 받침|

공격 총 600ms, attack_3 시작 360ms(60%), hitFrame=3. 발사 장부터 화살은 없으며 비행 화살은 생성하지 않는다. 활은 해부학적 왼손(목표인 화면 오른쪽으로 뻗는 팔), 오른손은 시위를 당긴다. 시전은 없다.

한 장 생성→직전 채택본과 얼굴·머리 크기·복장·활 쥔 손·접지·동작 진행 비교→채택/수정 기록→다음 장 생성 순서. 원본과 프롬프트를 남긴다. 제작 후 최근접 샘플링·팔레트 정규화·레이어 분리 및 재합성 검증. GIF 1×/4×, 전체 접촉 시트, 세 캐릭터 비교 1×/4×와 manifest를 만든다. 이 폴더 밖 파일은 변경하지 않는다.
